# MikroTik 移动应用

## 概述

该应用适用于 Android 和 iOS 操作系统。它是配置新设备的理想选择，为新路由器的基本设置提供简单友好的配置界面。同时，它还具备高级菜单，以满足经验丰富的用户需求。

## 下载应用

MikroTik 应用可在 App Store 和 Google Play 上下载，请参阅我们的网页 [软件部分](https://mikrotik.com/mobile_app) 获取直接下载链接，或扫描二维码。

使用 MikroTik 智能手机应用在现场配置路由器，或为您的 MikroTik 家庭接入点应用最基本的初始设置。

## 应用快速入门

- 扫描二维码并选择您偏好的操作系统。
- 安装并连接到您的无线网络。
- 打开应用。默认情况下，IP 地址和用户名已自动填入。
- 点击“连接”以建立连接。
- 选择“快速设置”，应用将通过几个简单步骤引导您完成所有基本配置设置。
