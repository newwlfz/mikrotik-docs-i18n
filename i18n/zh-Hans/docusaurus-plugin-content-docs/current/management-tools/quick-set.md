# 快速设置

> 快速设置（Quickset）是 MikroTik 路由器的简化配置向导，通过 HomeAP、CPE、CAP 等模式，为家庭或企业用户提供快速配置。它在一个界面中集成了无线网络、互联网连接、本地网络设置、VPN 选项和系统管理功能。

# 快速设置

### 概述

**快速设置（Quickset）** 是一个简单的配置向导页面，只需点击几下即可完成路由器配置。当用户在 Web 浏览器中打开默认 IP 地址 192.168.88.1 时，首先看到的便是此页面。

快速设置适用于所有带有出厂默认配置的设备。没有配置的设备必须手动配置。最常用且推荐的模式是 HomeAP（或 HomeAP dual，具体取决于设备）。此快速设置模式为家庭用户提供了最简单的术语和最常用的选项。

### 模式

根据路由器型号的不同，快速设置下拉菜单中可能提供不同的模式：

- **CAP**：受控接入点（Controlled Access Point），一种将由集中式 CAPsMAN 服务器管理的 AP 设备。仅在您已设置好 CAPsMAN 服务器时使用。
- **CPE**：客户端设备，用于连接接入点（AP）设备。提供扫描您所在区域 AP 设备的选项。
- **HomeAP**：大多数家庭用户的默认接入点配置页面。提供较少的选项和简化的术语。
- **HomeAP dual**：双频设备（2GHz/5GHz）。大多数家庭用户的默认接入点配置页面。提供较少的选项和简化的术语。
- **Home Mesh**：用于构建更大的 WiFi 网络。在路由器上启用 CAPsMAN 服务器，并将本地 WiFi 接口置于 CAPsMAN 控制之下。只需按住重置按钮启动其他 MikroTik WiFi AP，它们将加入此 HomeMesh 网络（详情请参阅其快速指南）。
- **PTP Bridge AP**：当您需要在同一网络中透明地互连两个远程位置时，将一个设备设置为该模式，将另一个设备设置为下一个（PTP Bridge CPE）模式。
- **PTP Bridge CPE**：当您需要在同一网络中透明地互连两个远程位置时，将一个设备设置为该模式，将另一个设备设置为前一个（PTP Bridge AP）模式。
- **WISP AP**：类似于 HomeAP 模式，但提供更高级的选项，并使用行业标准术语，如 SSID 和 WPA。

### HomeAP

如果您想快速配置家庭接入点，应使用此模式。

#### 无线

在此部分设置您的无线网络：

- **网络名称**：您的智能手机将如何识别您的网络？在此处设置您喜欢的任何名称。在 HomeAP dual 中，您可以将 2GHz（传统）和 5GHz（现代）网络设置为相同或不同的名称（请参阅常见问题解答）。使用您喜欢的任何名称，格式不限。
- **频率**：通常可以保留“自动”，这样路由器将扫描环境并选择占用最少的频率信道（仅执行一次）。如果您需要试验，请使用自定义选择。
- **频段**：通常保留默认值（2GHz b/g/n 和 5GHz A/N/AC）。
- **使用访问列表（ACL）**：如果您希望根据用户的 MAC（硬件）地址限制谁可以连接到您的 AP，请启用此选项。要使用此选项，首先需要允许这些客户端连接，然后使用下方的“复制到 ACL”按钮。这会将选定的客户端复制到访问列表中。构建访问列表（ACL）后，您可以启用此选项以禁止任何其他人尝试连接到您的设备。通常您可以忽略此选项，因为无线密码已提供了所需的限制。
- **WiFi 密码**：此处最重要的选项。设置一个安全密码，同时加密您的无线通信，连接无线网络时需要此密码。
- **接受 WPS**：使用此按钮授予对支持 WPS 连接模式的特定设备的访问权限。对于打印机和其他难以输入密码的外围设备非常有用。首先在客户端设备上启动 WPS 模式，然后在此处单击一次 WPS 按钮以允许该设备。该按钮仅生效几秒钟，并且按客户端单独操作。
- **访客网络**：适用于不需要知道您主 WiFi 密码的家庭访客。在此选项中为他们设置单独的密码。重要提示！访客用户将无法访问您局域网中的其他设备以及其他访客设备。此模式会启用桥接过滤器以防止这种情况。
- **无线客户端**：此表显示当前连接的客户端设备（其 MAC 地址、是否在访问列表中、上次使用的 IP 地址、连接时长、信号强度（以 dBm 和条形图显示））。

#### 互联网

- **端口**：选择连接到 ISP（互联网）调制解调器的端口。通常为 Eth1。
- **地址获取**：选择 ISP 分配 IP 地址的方式。请向您的服务提供商咨询此项及其他选项（IP 地址、子网掩码、网关）。
- **MAC 地址**：通常不应更改，除非您的 ISP 已将您锁定到特定 MAC 地址，并且您已更换为新路由器。
- **防火墙路由器**：为您的路由器和网络启用安全防火墙。务必确保选中此框，以防止从互联网端口访问您的设备。
- **MAC 服务器 / MAC Winbox**：允许从 LAN 端口侧以 MAC 地址模式使用 [Winbox 工具](https://mt.lv/winbox) 进行连接。当 IP 模式不可用时，可用于调试和恢复。仅限高级使用。
- **发现**：允许其他 RouterOS 设备通过型号名称识别该设备。

#### 本地网络

- **IP 地址**：通常可以保留默认值 192.168.88.1，除非您的路由器位于另一台路由器之后。为避免 IP 冲突，请更改为 192.168.89.1 或类似地址。
- **子网掩码**：在大多数情况下，您可以保留 255.255.255.0。
- **桥接所有 LAN 端口**：允许您的设备相互通信，即使您的电视通过以太网 LAN 线缆连接，而您的 PC 通过 WiFi 连接。
- **DHCP 服务器**：通常，您希望在家庭网络中自动配置 IP 地址，因此请保持 DHCP 设置开启并保留默认值。
- **NAT**：仅当您的 ISP 为路由器和本地网络都提供了公共 IP 地址时，才关闭此选项。否则，请保持 NAT 开启。
- **UPnP**：此选项为受支持的程序和设备（如 NAS 磁盘和点对点工具）启用自动端口转发（有些人称之为“向本地网络开放端口”）。请谨慎使用，因为此选项有时可能在您不知情的情况下将内部设备暴露给互联网。仅在明确需要时启用。

#### VPN

如果您想从互联网访问您的本地网络（和路由器），请使用安全的 VPN 隧道。此选项为您提供一个用于连接的域名，并启用 PPTP 和 L2TP/IPsec（推荐后者）。用户名为“vpn”，您可以指定自己的密码。您只需在此处启用它，然后在笔记本电脑或手机上提供地址、用户名和密码，连接到 VPN 后，您将拥有到家庭网络的安全加密连接。这在旅行时也很有用——您可以通过安全线路浏览互联网，就像从家中连接一样。这也有助于规避某些国家设置的地域限制。

#### 系统

- **检查更新**：始终使用此按钮确保您的设备是最新的。它会检查是否有可用的 RouterOS 更新版本，并进行安装。
- **密码**：设置设备配置页面本身的密码。确保任何人都无法访问您的路由器配置页面并更改设置。

### 常见问题解答

#### 问：快速设置与 Webfig 选项卡（其中出现大量新菜单）有何不同？

答：QuickSet 适用于只需要设备快速启动并运行的新用户。它在一个地方提供了最常用的选项。如果您需要更多选项，请完全不要使用任何 QuickSet 设置；点击“Webfig”打开高级配置界面。完整功能即已解锁。

#### 问：我可以同时使用快速设置和 Webfig 吗？

答：如果您打算使用快速设置，请仅使用快速设置，反之亦然。虽然不冲突的设置可以这样配置，但不建议混合使用这些菜单。路由器模式和桥接模式有什么区别？桥接模式将所有接口添加到桥接中，允许转发 Layer2 数据包（充当集线器/交换机）。在路由器模式下，数据包通过使用 IP 地址和 IP 路由在 Layer3 中转发（充当路由器）。

#### 问：在 HomeAP 模式下，2GHz 和 5GHz 网络名称应该相同还是不同？

答：如果您希望所有客户端设备（如电视、手机、游戏机）自动选择最佳首选网络，请将名称设置为相同。如果您想强制客户端设备使用更快的 5GHz 802.11ac 连接，请将名称设置为唯一。

#### 问：我可以在没有安全设置的情况下创建 AP——无密码，或者在使用快速设置时连接到这样的 AP 吗？

答：快速设置默认使用 WPA2 预共享密钥。这意味着最小密码长度为 8 个字符，设备只能连接到 WPA2 安全的 AP 或自身作为 AP 提供服务。对于无安全设置的配置，您需要使用 WinBox、Webfig 或控制台手动配置。
