# 引言

MikroTik RouterOS 是驱动 MikroTik 路由器、交换机和无线设备的网络操作系统。它将路由、防火墙、VPN、无线管理、服务质量、自动化及监控工具整合于单一平台，适用于构建和运维各种规模的网络。

## 文档组织结构

左侧边栏是手册的导航地图。分类按从通用知识到特定功能的顺序排列，因此从头到尾阅读的读者将从初次接触设备逐步过渡到高级配置。

流程如下：

- **入门指南** 涵盖如何连接新设备、首次配置、安装、授权、升级及基本安全设置。
- 后续主题章节各聚焦系统的一个领域：管理工具、系统信息与实用程序、诊断与监控、硬件、有线和无线连接、移动网络、桥接与交换、网络服务、路由协议、防火墙与服务质量、虚拟专用网络、用户管理、高可用性、物联网、存储及容器。
- **开发者指南** 涵盖脚本编写及面向 RouterOS 自动化用户的编程接口。
- **CLI 参考** 位于末尾，作为查阅部分而非阅读部分。

如果设备是全新的，请从入门指南开始。基础系统就绪后，再转向与任务匹配的主题章节。将 CLI 参考视为工作中查阅的字典，而非从头到尾阅读的章节。

## CLI 参考

[CLI 参考](./cli-reference/) 按控制台路径记录了 RouterOS 命令菜单和属性。通过菜单查找功能，例如 `/ip/address` 或 `/routing/bgp`，以查看可用命令、配置对象以及每个属性的类型和默认值。

此部分由 RouterOS 系统自动生成，而非人工编写。菜单、命令和参数类型均从软件中提取，因此参考内容与实际系统暴露的功能保持一致。每个参数都列出了参数类型，相关图例说明位于 CLI 参考起始页。由于该部分是自动生成的，请按控制台路径查找并依赖搜索，而非期望每个主题都有手工编辑的文章。

## 面向 AI 工具的机器可读访问

整个手册以纯文本格式发布，不仅可在浏览器中阅读，还可供检索管道、助手及其他自动化工具读取。

可用端点如下：

| 端点 | 用途 |
| --- | --- |
| [`/llms.txt`](pathname:///llms.txt) | 每个页面的索引，附有简短描述和链接。遵循 [llms.txt 约定](https://llmstxt.org)，作为工具首先读取以发现内容的入口点。 |
| [`/llms-full.txt`](pathname:///llms-full.txt) | 整个手册合并为一个纯文本文件，适用于批量摄取或加载完整本地副本。 |
| 每页 Markdown | 任意页面的原始源文件。在文档地址后附加 `.md`，例如 [`/docs/introduction.md`](pathname:///docs/introduction.md)，即可获取其背后的 Markdown。 |
| [`/sitemap.xml`](pathname:///sitemap.xml) | 标准站点地图，列出每个页面供爬虫和索引器使用。站点的 `robots.txt` 允许标准及 AI 爬虫访问。 |

常见模式是先读取 `/llms.txt` 以找到相关页面，然后获取所需的各个 `.md` 页面以获取详细信息。如需一次性获取完整语料库，请加载 `/llms-full.txt`。这些文件在每次构建时重新生成，因此与已发布页面保持同步。
