# Cloud Hosted Router, CHR

Cloud Hosted Router (CHR) 是 RouterOS 的虚拟化版本，专为在 x86_64 虚拟环境中运行而设计。它提供了与 MikroTik 硬件设备相同的核心路由、防火墙、VPN 及管理功能。

本节涵盖 CHR 的安装、部署及授权相关内容。
