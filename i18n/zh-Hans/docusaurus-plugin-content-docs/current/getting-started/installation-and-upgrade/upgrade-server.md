# 升级服务器

> 了解 RouterOS 如何连接 MikroTik 升级服务器以检查并下载新版本，以及如何排查连接问题。

当您检查更新时，RouterOS 会联系 `upgrade.mikrotik.com` 以确定适用于您设备和许可证等级的最新可用版本。如果无法访问服务器或 DNS 名称无法解析，升级检查将失败或返回过时信息。

## 升级检查的工作原理

RouterOS 软件包更新机制执行以下步骤：

1. 设备向 `upgrade.mikrotik.com` 发送请求，包含当前 RouterOS 版本、架构和许可证等级。
2. 服务器将此信息与您选择的发布链（长期版、稳定版、测试版或开发版）进行匹配，并返回最新的兼容版本。
3. 如果有更新版本可用，设备直接从同一服务器下载相应的 `.npk` 软件包。

## 故障排查

如果设备未检测到可用升级，请验证其能否解析并访问升级服务器。

### 检查 DNS 解析

运行以下命令以验证设备能否解析服务器地址：

```ros
:put [:resolve upgrade.mikrotik.com]
```

结果应为 `159.148.147.251`。如果地址无法解析或解析到不同的 IP，请检查您的 DNS 设置。更多信息请参阅 [DNS](../../network-management/dns.md) 文章。

### 检查服务器可达性

确认 DNS 解析后，验证设备能否访问服务器：

```ros
/tool/ping address=159.148.147.251
```

如果 ping 失败，请检查您的防火墙规则、路由或上游连接。设备必须能够通过端口 443（HTTPS）访问服务器才能下载软件包。
