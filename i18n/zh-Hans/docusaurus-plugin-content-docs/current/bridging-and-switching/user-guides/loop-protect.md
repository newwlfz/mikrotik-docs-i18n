# Loop Protect（环路保护）

> Loop Protect（环路保护）通过检测并禁用接收到自身环路保护数据包的接口来防止二层环路，并支持可配置的发送间隔和禁用时间。它支持以太网、VLAN、EoIP 和 VxLAN 接口，不过对于桥接场景，仍建议使用 (R/M)STP。

# Loop Protect（环路保护）

环路保护功能通过发送环路保护协议数据包，并在接口接收到源自自身的环路保护数据包时将其关闭，从而防止二层环路。该功能通过将接收到的环路保护数据包的源 MAC 地址与启用了环路保护的接口的 MAC 地址进行比对来工作。如果匹配成功，环路保护将禁用接收到该环路保护数据包的接口。系统会记录一条日志消息以警告此事件，并在接口上标记环路保护注释。RouterOS 的环路保护功能可用于桥接接口，也可用于在 RouterBoard 交换芯片中设置为交换模式的以太网接口。

Loop Protect 支持以太网、VLAN、EoIP 和 VxLAN 接口，其数据包封装使用 EtherType 0x9003。  
环路保护数据包的发送间隔和接口禁用时间均可调整。配置更改或禁用时间到期会重置接口上的环路保护。

:::warning
尽管环路保护可以工作在已添加到桥接的接口上，但仍建议使用 (R/M)STP 而非环路保护，因为 (R/M)STP 与大多数交换机兼容，并且 STP 变体提供了更多配置选项，以便对网络进行微调。
:::

**子菜单:** `/interface/ethernet, /interface/vlan, /interface/eoip, /interface/eoipv6, /interface/vxlan`

| 属性 | 描述 |
| :-- | :-- |
| **loop-protect** (*on \| off \| default*; 默认值: **default**) | 在所选接口上启用或禁用环路保护。**default** 等同于关闭。 |
| **loop-protect-send-interval** (*时间间隔*; 默认值: **5s**) | 设置环路保护数据包在所选接口上的发送频率。 |
| **loop-protect-disable-time** (*时间间隔 \| 0*; 默认值: **5m**) | 设置检测到环路时，所选接口被禁用的时长。**0** - 永久禁用。 |

### 只读属性

| 属性 | 描述 |
| :-- | :-- |
| **loop-protect-status** (*on \| off \| disable*) | on - 环路保护功能已开启，接口正在发送和监听环路保护数据包；off - 环路保护功能已关闭；disable - 环路保护功能已开启，接口已接收到环路保护数据包并自行禁用以防止环路。 |
