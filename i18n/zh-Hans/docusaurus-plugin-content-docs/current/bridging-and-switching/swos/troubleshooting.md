# 无法升级 SwOS

---

## 概述

支持 SwOS 的 MikroTik 交换机在闪存中存储两个独立的固件镜像：一个**主**（活动）镜像和一个**备份**镜像。在正常操作下，设备从主镜像启动。当启动固件升级时——无论是通过 Web 界面自动执行还是通过文件上传手动执行——设备会将新镜像写入主槽位并重启进入该镜像。

升级失败通常由以下原因之一引起：

- 选择了错误的固件文件（错误的型号或固件分支）
- 写入操作中断导致主镜像损坏
- 网络连接问题导致无法从 MikroTik 服务器自动下载
- 在双启动设备上：设备模式策略限制操作系统切换（RouterOS 7.17+）

仅支持 SwOS 的设备与双启动设备需要不同的恢复流程，下文将分别说明。

---

## 开始之前

> **警告：** 本文所述的重置按钮操作将擦除活动配置并加载出厂默认设置。请先通过 **System** 选项卡导出配置备份后再继续操作。

在尝试手动升级之前，请确认所需的固件文件。每个交换机系列使用专用的固件二进制文件——跨系列固件文件不可互换，否则将被拒绝或导致启动失败。适用于您设备的正确文件可在以下位置找到：

[mikrotik.com 软件下载中心](https://mikrotik.com/download)

---

## 解决方案

### 仅支持 SwOS 的设备（CSS 系列）

这些设备不运行 RouterOS，也没有串行控制台启动菜单。恢复依赖于存储在受保护闪存分区中的硬件备份固件。

**步骤 1 — 尝试手动固件上传**

在 SwOS Web 界面中导航到 **Upgrade** 选项卡，选择适用于您设备型号的正确 `.swos` 固件文件，然后点击 **Upgrade**。写入过程中请勿中断电源。上传完成后，设备将自动重启。重新加载 Web 界面并验证 **System** 选项卡中显示的固件版本。

**步骤 2 — 通过硬件重置启动备份固件**

如果手动上传失败或升级尝试后设备无法访问，可以使用重置按钮强制加载备份（主）固件：

1. 断开设备电源。
2. 按住 **Reset** 按钮并重新接通电源。
3. 持续按住按钮约 5 秒，直到设备完成启动序列。
4. 松开按钮。

设备将加载备份固件并应用出厂默认配置。可通过 **192.168.88.1** 或 DHCP 分配的地址访问设备。

**步骤 3 — 重新尝试手动固件上传**

设备在备份固件上可访问后，重复步骤 1 中的手动升级流程。备份固件环境提供了干净的状态，升级更有可能成功。

---

### 双启动设备（CRS 系列）

双启动设备同时存储 SwOS 和 RouterOS，可启动进入任一操作系统。这提供了额外的恢复路径，包括通过 RouterOS CLI 进行升级。

**步骤 1 — 尝试手动固件上传**

与仅支持 SwOS 的设备相同，首先尝试通过 SwOS Web 界面中的 **Upgrade** 选项卡，使用适用于您设备的正确固件文件进行手动升级。

**步骤 2 — 通过串行控制台启动备份 SwOS**

如果手动上传失败，请使用以下参数通过串行控制台线缆连接到设备：

| 参数 | 值 |
| --- | --- |
| 波特率 | 115200 |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | 无 |
| 流控 | 无 |

在启动菜单提示符下，选择：

```
p - boot primary SwOS
```

这将加载出厂备份 SwOS 镜像。设备可访问后，按步骤 1 所述重新尝试手动固件上传。

**步骤 3 — 通过重置按钮启动 RouterOS（无控制台访问）**

如果没有可用的串行控制台端口或手边没有线缆，可以使用重置按钮强制设备进入 RouterOS：

1. 在设备通电状态下，按住 **Reset** 按钮。
2. 持续按住直到用户 LED 开始闪烁（约 5 秒）。
3. 松开按钮。

设备将重置 RouterOS 配置为出厂默认设置并启动进入 RouterOS。

> **警告：** 此过程会重置 RouterOS 配置。如果设备之前运行的是 RouterOS，请确保在继续操作前存在 RouterOS 配置备份。

**步骤 4 — 从 RouterOS CLI 升级 SwOS**

启动进入 RouterOS 后，无需使用 Web 界面即可直接升级 SwOS。以下命令将获取并安装适用于该设备的最新 SwOS 固件：

```
/system swos upgrade
```

执行此命令需要互联网访问，以便从 MikroTik 更新服务器解析并下载正确的固件包。执行前请验证网络连接。

**步骤 5 — 设备模式限制（RouterOS 7.17 及更高版本）**

从 RouterOS **v7.17** 开始，`device-mode` 策略限制双启动硬件上 SwOS 与 RouterOS 之间的操作系统切换。如果升级命令失败或操作系统切换被阻止，请使用以下命令显式允许切换：

```
/system/device-mode/update routerboard=yes
```

此命令必须在 RouterOS 中执行，然后才能重新尝试 SwOS 升级或切换回 SwOS。

**步骤 6 — 返回 SwOS**

从 RouterOS 成功更新 SwOS 固件后，将默认启动目标设置回 SwOS 并重启设备：

```
/system routerboard settings set boot-os=swos
/system reboot
```

设备将重新启动并加载新安装的 SwOS 固件。
