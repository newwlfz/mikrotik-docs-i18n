# CSS106 (RB260) 系列手册

## 特性

| 特性 | 描述 |
| --- | --- |
| **转发** | 全线速无阻塞交换，主机表支持多达 2k 条 MAC 条目，转发数据库基于 SVL 或 IVL，端口隔离，端口锁定，巨帧支持 - 9198 字节 |
| **生成树协议** | 支持 RSTP |
| **组播转发** | 支持 IGMP Snooping |
| **镜像** | 基于端口的镜像 |
| **VLAN** | 完全兼容 IEEE 802.1Q，基于端口的 VLAN，VLAN 过滤 |
| **服务质量（QoS）** | 入口流量限制（通过 ACL），出口流量限制 |
| **访问控制列表** | 入口 ACL 表，最多 32 条 ACL 规则（受 SwOS 限制），基于端口、L2、L3、L4 协议头字段的分类，ACL 操作包括过滤、转发及修改协议头字段 |

## 连接交换机

打开您的 Web 浏览器，输入交换机的 IP 地址（默认为 192.168.88.1），将出现登录界面。交换机也可以运行 DHCP 客户端，请检查 DHCP 服务器是否分配了不同的 IP 地址。

![Swos login css106](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css106-01.webp)

SwOS 默认 IP 地址：**192.168.88.1**，用户名：**admin**，无密码。

可以使用 [MikroTik 邻居发现](../../system-information-and-utilities/neighbor-discovery) 来发现 MikroTik 交换机的 IP 地址。不支持 LLDP。

## 界面概览

SwOS 界面菜单由多个标签页组成：Link、SFP、Forwarding、RST、Statistics、Errors、VLAN、VLANs、Hosts、IGMP Groups、SNMP、ACL、System 和 Upgrade。

SwOS 配置工具中按钮的说明：

- **Append** - 在列表末尾添加新条目
- **Apply All** - 应用当前配置更改
- **Cut** - 从列表中移除条目
- **Clear** - 重置条目属性
- **Discard Changes** - 丢弃未保存的配置
- **Insert** - 在列表中插入新条目（置于当前条目之前）
- **Sort** - 按 VLAN ID 对 VLAN 表排序；按 MAC 地址对主机表排序
- **Change Password** - 更改交换机密码
- **Logout** - 退出当前交换机
- **Reboot** - 重启交换机
- **Reset Configuration** - 将配置重置为出厂默认值
- **Choose File** - 浏览升级或备份文件
- **Upgrade** - 使用所选文件升级交换机固件
- **Download & Upgrade** - 自动尝试下载并升级固件，运行 Web 浏览器的 PC 需能访问互联网
- **Restore Backup** - 使用所选备份文件恢复交换机
- **Save Backup** - 从交换机生成并下载备份文件

> **注意：** 每个 RouterBOARD 交换机系列都有其专属固件，不能安装在其他系列型号上！CSS106-5G-1S (RB260GS) 和 CSS106-1G-4P-1S (RB260GSP) 支持 SwOS v2.0 及更新版本。升级设备时，将首先加载主固件，然后进行升级。如果选择了错误的固件文件，设备将继续使用主固件运行，您将能够选择正确的文件。

## 系统

System 标签页执行以下功能：

- 交换机常规信息
- 交换机管理
- 配置重置
- 配置备份与恢复

> **注意：** SwOS 使用一种简单的算法来确保 TCP/IP 通信——它仅回复数据包来源的同一 IP 和 MAC 地址。这样设备本身无需设置默认网关。

![Swos system1](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css106-02.webp)

| 属性 | 描述 |
| --- | --- |
| **Address Acquisition** | 指定使用的地址获取方式：`DHCP with fallback` - 交换机尝试从 DHCP 服务器请求 IPv4 地址。如果请求失败，则可通过 **Static IP Address** 值访问交换机`static` - 地址设置为 **Static IP Address** 值（仅 IPv4）`DHCP only` - 交换机使用 DHCPv4 客户端获取地址 |
| **Static IP Address** | 当 **Address Acquisition** 设置为 `DHCP with fallback` 或 `static` 时交换机的 IP 地址 |
| **Identity** | 交换机名称（用于 MikroTik 邻居发现协议） |
| **Allow From** | 允许访问交换机的 IP 地址或网络。默认值为 `0.0.0.0/0` - 任意地址。 |
| **Allow From Ports** | 允许访问服务的交换机端口列表 |
| **Allow From VLAN** | 允许访问服务的 VLAN ID。请确保先配置 VLAN 和 VLANs 页面 |
| **Watchdog** | 启用或禁用系统看门狗。发生故障时它将重置交换机的 CPU |
| **Independent VLAN Lookup** | 启用或禁用主机表中用于数据包转发的独立 VLAN 查找 |
| **IGMP Snooping** | 启用或禁用 IGMP Snooping |
| **IGMP Fast Leave** | 启用或禁用交换机端口上的 IGMP 快速离开功能。此属性仅在启用 IGMP Snooping 时生效 |
| **Mikrotik Discovery Protocol** | 启用或禁用 MikroTik 邻居发现协议 |
| **Port1 PoE In Long Cable** | 如果启用，将关闭所有 PoE 输出端口的短路检测，以允许使用更长的以太网线缆。这是潜在危险的设置，应谨慎使用。（CSS106-1G-4P-1S 型号） |
| **MAC Address** | 交换机的 MAC 地址（只读） |
| **Serial Number** | 交换机的序列号（只读） |
| **Board Name** | MikroTik 型号名称（只读） |
| **Voltage** | 显示以伏特为单位的输入电压（只读，CSS106-1G-4P-1S 型号） |
| **Temperature** | 以摄氏度为标度显示 PCB 温度（只读，CSS106-1G-4P-1S 型号） |

## 链路

- 配置以太网和 SFP 端口
- 监控以太网和 SFP 端口的状态

![Swos link css106](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css106-04.webp)

| 属性 | 描述 |
| --- | --- |
| **Enabled** | 启用或禁用端口 |

| **Link Status** | 当前链路状态（只读） |
| **Auto Negotiation** | 启用或禁用自动协商（某些 SFP 模块可能需要禁用它才能工作） |

### PoE

PoE 设置更改 CSS106-1G-4P-1S 端口2-端口5 的以太网供电输出，并显示 PoE 状态和测量值。

![740px Swospoe2](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css106-05.webp)

| 属性 | 描述 |
| --- | --- |
| **PoE Out** | 设置端口的 PoE 输出模式：`off` - 所有检测和 PoE 输出均关闭`auto` - 根据空闲线对上的电阻进行检测，以检查端口是否具有 PoE 能力。要使端口开启，测量值应在 3kΩ 至 26.5kΩ 范围内`on` - 无论端口上的电阻如何，PoE 输出均启用。***请谨慎使用，否则可能损坏所连接的设备！***`calibr` - 手动端口 PoE 输出重新校准。如果为连接的设备供电时偶尔出现问题，则可能需要此操作。 |
| **PoE Priority** | PoE 输出供电的端口优先级。如果安装超过可用功率预算，则优先级最低的端口将首先被关闭。`1` - 最高优先级端口；`4` - 最低优先级端口 |
| **PoE Status** | 端口当前的 PoE 输出状态：`disabled` - PoE 输出已关闭`waiting for load` - `auto` 模式检测到电阻超出范围以开启 PoE 输出`powered on` - PoE 输出已开启`short circuit` - 如果检测到短路，PoE 输出将关闭，以确保受电设备无额外损坏且供电设备无损坏`voltage too low` - 供电电压不足以通过 PoE 输出开启设备`current too low` - 供电电流不足以通过 PoE 输出开启设备`waiting for cable disconnect` - 使用 `calibr` 进行的手动重新校准已检测到连接的设备，并等待断开连接以完成重新校准过程 |
| **PoE Current** | 显示端口上以毫安为单位的当前使用电流 |
| **PoE Power** | 显示端口上以瓦特为单位的 PoE 输出功率 |

## RSTP

RSTP 菜单中提供每端口和全局 RSTP 配置及监控。

![Swos RSTP css106](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css106-08.webp)

| 属性 | 描述 |
| --- | --- |
| **RSTP** | 启用或禁用此端口上的 STP/RSTP 功能 |
| **Mode** | 显示特定端口上的 STP/RSTP 功能模式（只读）：`RSTP``STP` |
| **Role** | 显示特定端口的角色（只读）：`root` - 面向根桥的端口，将用于与根桥之间转发流量`alternate` - 面向根桥但不转发流量的端口（根端口的备份）`backup` - 背向根桥但不转发流量的端口（非根端口的备份）`designated` - 背向根桥且将转发流量的端口`disabled` - 严格来说不属于 STP 的端口（RSTP 功能已禁用） |
| **Root Path Cost** | 显示面向根桥的端口的根路径开销（只读） |
| **Type** | `edge` - 不应接收任何 BPDU 的端口，应连接到终端设备（只读）`point-to-point` - 在全双工链路上运行的端口，可以是 STP 的一部分并处于转发状态（只读） |
| **State** | 显示每个端口的状态（只读）：`forwarding` - 端口参与流量转发并学习 MAC 地址，接收 BPDU`discarding` - 端口不参与流量转发且不学习 MAC 地址，接收 BPDU`learning` - 端口不参与流量转发，但正在学习 MAC 地址 |
| **Bridge Priority (hex)** | 用于根桥选择的 RSTP 桥优先级 |
| **Port Cost Mode** | 根据链路速度自动检测 RSTP 端口开销的两种方法。`short`: 10G - 2; 1G - 4; 100M - 10; 10M - 100`long`: 10G - 2000; 1G - 20000; 100M - 200000; 10M - 2000000 |
| **Forward Reserved Multicast** | 是否转发 **01:80:C2:00:00:0x** 范围内的 IEEE 保留组播 MAC 地址。符合 R/M/STP 标准的交换机应避免转发这些数据包。如果启用此设置，SwOS 将转发保留的组播 MAC 数据包并禁用 RSTP：- 交换机将不处理传入的 BPDU（桥接协议数据单元）- 也不会发送自己的 BPDU- 桥优先级和每端口 RSTP 配置设置将不再生效。启用保留 MAC 地址的转发可能会影响依赖这些地址的某些协议。建议仅在绝对必要时启用转发，例如在透明桥接设置中（如扩展长链路、将桥用作介质转换器或进行网络分析）。值得注意的 MAC 地址和协议示例（由 RouterOS 使用）：`01:80:C2:00:00:00` - 生成树协议（STP）`01:80:C2:00:00:01` - 以太网流量控制`01:80:C2:00:00:02` - 链路聚合控制协议（LACP）`01:80:C2:00:00:03` - Dot1x 客户端和服务器`01:80:C2:00:00:08` - 生成树协议（用于 802.1ad 桥，使用 `ether-type=0x88a8`）`01:80:C2:00:00:0D` - 多 VLAN 注册协议（用于 802.1ad 桥，使用 `ether-type=0x88a8`）`01:80:C2:00:00:0E` - 链路层发现协议、多机箱链路聚合组和精确时间协议流量控制 MAC 地址 `01:80:C2:00:00:01` 是一个例外——SwOS 不会转发它。 |
| **Root Bridge** | 网络中选定的根桥的优先级和 MAC 地址（只读） |

## VLAN 和 VLANs

交换机端口的 VLAN 配置。

![740px Swos vlan2](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css106-11.webp)

| 属性 | 描述 |
| --- | --- |
| **VLAN Mode** | 入口端口的 VLAN 模式：`disabled` - 不使用 VLAN 表；交换机忽略带标签数据包的 VLAN 标签部分`optional` - 处理 VLAN 表中不存在的带 VLAN 标签 ID 的数据包，如同处理不带 VLAN 标签的数据包`enabled` - 丢弃 VLAN 表中不存在的带 VLAN 标签 ID 的数据包。不带 VLAN 标签的数据包被视为带有 `Default VLAN ID` 的带标签数据包`strict` - 与 `enabled` 相同，但还会检查入站接口的 VLAN 支持（丢弃 VLAN 表中不存在的带 VLAN 标签 ID 和入口端口的数据包） |
| **VLAN Receive** | 定义入口端口允许的数据包类型：`any` - 允许特定端口上的带标签和不带标签的数据包`only tagged` - 仅允许带 VLAN 标签的数据包`only untagged` - 仅允许不带 VLAN 标签的数据包 |
| **Default VLAN ID** | 交换机将不带标签和带有 "Default VLAN ID" 标签的入口数据包视为带有此 VLAN ID 标签。如果数据包的 VLAN ID 与 "Default VLAN ID" 匹配，它也用于对出口流量进行去标签。仅当出口端口指定了 `VLAN Header = add if missing` 时，才会添加 VLAN 标签本身 |
| **Force VLAN ID** | 是否将 `Default VLAN ID` 应用于带有 VLAN 标签的传入数据包 |
| **VLAN Header** | `leave as is` - 如果存在 VLAN 头，则保持不变`always strip` - 如果存在 VLAN 头，则从数据包中移除`add if missing` - 如果不存在 VLAN 头，则添加到数据包（VLAN ID 将是入口端口的 `Default VLAN ID`） |

> **注意：** 运行 SwOS 2.12 版本的 CSS106 设备在端口上启用 VLAN 过滤（VLAN 模式 **enabled** 或 **strict**）时可以过滤 RSTP BPDU 数据包。对于 SwOS 2.13 版本，建议在 trunk 端口上将 VLAN Receive 设置为 **any**。

> **注意：** VLAN 模式 `enabled` 和 `strict` 要求 VLANs 表中存在 VLAN ID 1，以允许不带标签的流量访问交换机本身。

VLAN 表指定了带有 IEEE 802.1Q 标签的数据包的转发规则。基本上，该表包含将特定 VLAN 标签 ID 映射到一个或多个端口组的条目。带有 VLAN 标签的数据包通过相应表条目中设置的一个或多个端口离开交换机。VLAN 表与目的 MAC 查找协同工作以确定出口端口。VLAN 表最多支持 250 个条目。

![Swos vlan css106](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css106-12.webp)

| 属性 | 描述 |
| --- | --- |
| **VLAN ID** | 数据包的 VLAN ID |
| **IVL** | 启用或禁用独立 VLAN 学习（IVL） |
| **IGMP Snooping** | 在定义的 VLAN 上启用或禁用 IGMP Snooping。启用后，交换机将侦听来自定义 VLAN 的 IGMP 加入和离开请求，并且仅将流量转发到已从定义 VLAN 发送 IGMP 成员资格请求的端口。禁用后，交换机将向所有 VLAN 成员端口泛洪组播流量。 |
| **Ports** | 每个端口对每个 VLAN ID 都有单独的 *VLAN header* 选项。根据 *VLAN mode*，如果在此表中进行查找，则数据包的出口操作由此选项处理。**VLAN 标签页**中的出口选项将被忽略。 |

### VLAN 配置示例

#### Trunk 和 Access 端口

![Access ports small](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css106-13.webp)

1. 在 System 菜单中启用独立 VLAN 学习（IVL）。

![Css106 ivl](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css106-14.webp)

1. 在 VLANs 菜单中添加 VLAN 条目，指定端口成员资格，并启用 IVL。可以使用默认的 "leave as is" 端口设置；标签和去标签行为可通过 "Default VLAN ID" 设置更改，请参阅下一步。

![Css access trunk vlans](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css106-15.webp)

1. 在 VLAN 菜单中，在计划的 access 端口（不带标签）上配置 Default VLAN ID，选择正确的 VLAN Receive 设置（Port2 仅带标签，Port3-5 仅不带标签），并启用严格的 VLAN 过滤以确保只有允许的 VLAN 可以通过端口。

![Css106 access vlan](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css106-16.webp)

> **注意：** 运行 SwOS 2.12 版本的 CSS106 设备在端口上启用 VLAN 过滤（VLAN 模式 **enabled** 或 **strict**）时可以过滤 RSTP BPDU 数据包。对于 SwOS 2.13 版本，建议在 trunk 端口上将 VLAN Receive 设置为 **any**。

#### Trunk 和 Hybrid 端口

![Hybrid ports small](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css106-17.webp)

1. 在 System 菜单中启用独立 VLAN 学习（IVL）。

![Css106 ivl 1](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css106-18.webp)

1. 在 VLANs 菜单中添加 VLAN 条目，指定端口成员资格，并启用 IVL。可以使用默认的 "leave as is" 端口设置；标签和去标签行为可通过 "Default VLAN ID" 设置更改，请参阅下一步。

![Css hybrid vlan](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css106-19.webp)

1. 在 VLAN 菜单中，在计划的 hybrid 端口（用于不带标签的 VLAN）上配置 Default VLAN ID，选择正确的 VLAN Receive 设置（Port2 仅带标签，Port3-5 任意），并启用严格的 VLAN 过滤以确保只有允许的 VLAN 可以通过端口。

![Css hybrid vlans](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css106-20.webp)

> **注意：** 运行 SwOS 2.12 版本的 CSS106 设备在端口上启用 VLAN 过滤（VLAN 模式 **enabled** 或 **strict**）时可以过滤 RSTP BPDU 数据包。对于 SwOS 2.13 版本，建议在 trunk 端口上将 VLAN Receive 设置为 **any**。

#### 管理访问

在此示例中，将创建 VLAN 200 上的交换机管理访问。配置方案与 "**Trunk 和 Access 端口**" 相同，步骤 **1.、2.、3.** 完全相同。额外的**第 4** 步需要在 System 菜单中指定管理 VLAN ID。应用配置后，交换机将仅响应 Port2 上带标签的 VLAN 200 数据包和 Port3 上不带标签的数据包。DHCP 客户端也将在指定的 VLAN ID 中工作。

![Css106 system vlan](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css106-21.webp)

> **警告：** 如果 VLAN 设置未正确配置，更改管理 VLAN 可能完全禁用对交换机管理的访问。更改此设置前请保存配置备份，如果管理访问丢失，请使用 [重置](#reset)。

## 主机

此表表示动态学习的 MAC 地址到端口映射条目。它可以包含两种条目：动态和静态。动态条目自动添加——这也称为学习过程：当交换机从某个端口接收到数据包时，它将数据包的源 MAC 地址 X 和接收数据包的端口添加到主机表中，因此当数据包到达且目的 MAC 地址为 X 时，它知道应将数据包转发到哪个端口。如果目的 MAC 地址不在主机表中，则它将数据包转发到组中的所有端口（泛洪）。动态条目大约需要 5 分钟超时。

CSS106 系列交换机支持 2048 条主机表条目。

![Swos hosts css106](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css106-22.webp)

| 属性 | 描述 |
| --- | --- |
| **Port** | 数据包应转发到的端口（只读） |
| **MAC** | 学习到的 MAC 地址（只读） |
| **VLAN ID** | 学习到的 VLAN ID（只读） |

### 静态主机

如果已存在具有相同 MAC 地址的动态条目，静态条目将接管动态条目。添加静态条目还提供对附加功能的访问。

![740px Swos static2](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css106-23.webp)

| 属性 | 描述 |
| --- | --- |
| **Ports** | 数据包应转发到的端口 |
| **MAC** | MAC 地址 |
| **VLAN ID** | VLAN ID |
| **Drop** | 可以丢弃来自特定端口的具有特定 MAC 地址的数据包 |
| **Mirror** | 可以克隆数据包并将其发送到镜像目标端口 |

## SNMP

SwOS 支持 SNMP v1 和 v2c（响应 GetRequest、GetNextRequest 和 GetBulkRequest），并使用 IF-MIB、SNMPv2-MIB、BRIDGE-MIB 和 MIKROTIK-MIB（仅用于健康、PoE 输出和 SFP 诊断）。不支持 SNMP trap 和写入 SwOS 配置。

可用的 SNMP 数据：

- 系统信息
- 系统运行时间
- 端口状态
- 接口统计信息
- 主机表信息

![Swos snmp2](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css106-27.webp)

| 属性 | 描述 |
| --- | --- |
| **Enabled** | 启用或禁用 SNMP 服务 |
| **Community** | SNMP 团体名称 |
| **Contact Info** | NMS 的联系信息 |
| **Location** | NMS 的位置信息 |

## ACL

访问控制列表（ACL）规则表是一个非常强大的工具，允许基于 L2、L3 和 L4 协议头字段条件进行线速数据包过滤、转发和 VLAN 标记。SwOS 允许您实现有限数量的访问控制列表规则（32 条仅使用 L2 条件的简单规则；16 条同时使用 L2 和 L3 条件的规则；或 8 条使用所有 L2、L3 和 L4 条件的高级规则）。每条规则包含条件部分和操作部分。

![740px Swos acl2](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css106-28.webp)

**条件参数**

| 属性 | 描述 |
| --- | --- |
| **From** | 数据包进入的端口 |
| **MAC Src** | 源 MAC 地址和掩码 |
| **MAC Dst** | 目的 MAC 地址和掩码 |
| **Ethertype** | 以太网帧负载中封装的协议 |
| **VLAN** | VLAN 头存在性：`any` / `present` / `not present` |
| **VLAN ID** | VLAN 标签 ID |
| **Priority** | VLAN 标签中的优先级 |
| **IP Src** (IP/netmask:port) | 源 IPv4 地址、网络掩码和 L4 端口号 |
| **IP Dst** (IP/netmask:port) | 目的 IPv4 地址、网络掩码和 L4 端口号 |
| **Protocol** | IP 协议 |
| **DSCP** | IP DSCP 字段 |

**操作参数**

| 属性 | 描述 |
| --- | --- |
| **Redirect To** | 是否强制指定新的目的端口（如果启用 "Redirect To" 但未在 "Redirect To Ports" 中指定端口，数据包将被丢弃） |
| **Redirect To Ports** | 重定向目的端口 |
| **Mirror** | 克隆数据包并将其发送到镜像目标端口 |
| **Rate** | 限制带宽（bps） |
| **Set VLAN ID** | 如果存在 VLAN 标签，则更改 VLAN 标签 ID |
| **Priority** | 如果存在 VLAN 标签，则更改 VLAN 标签优先级位 |

## 重置

CSS106-5G-1S 和 CSS106-1G-4P-1S 具有内置的备份 SwOS 固件，可在标准固件损坏或升级失败时加载：

- 在设备启动时按住 Reset 按钮几秒钟将重置配置并加载备份固件。
- 加载备份固件后，可以使用 Web 浏览器连接到 192.168.88.1（或 DHCP 服务器分配的地址）并安装新的 SwOS 固件。
