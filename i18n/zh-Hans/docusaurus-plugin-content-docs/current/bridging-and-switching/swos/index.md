# SwOS 简介

SwOS 是一款专为 MikroTik 交换硬件管理而设计的轻量级操作系统。它能够在所有标准以太网帧上提供最大线速二层转发能力，无缝处理 IPv4、IPv6 及非 IP 流量。

### 核心与高级功能

除标准托管交换机功能外，SwOS 还提供了一套强大的网络功能套件：

* **VLAN 管理：** 全面支持复杂 VLAN 配置，包括接入端口和 trunk 端口。
* **流量控制：** 高级广播风暴控制、带宽限制以及端口到端口转发设置。
* **监控与镜像：** 入口/出口流量镜像以及实时端口级统计。
* **安全与过滤：** 精细的访问控制列表（ACL）引擎，能够根据 MAC、IP 和端口级规则匹配流量。
* **硬件卸载：** 在支持的设备型号上，直接通过硬件驱动操作特定 MAC 和 IP 头部字段。

:::note 管理限制
SwOS 仅通过标准 Web 浏览器（HTTP）在 IPv4 上进行配置。它不支持通过串行控制台/SSH 的命令行界面（CLI）访问、API 访问、WinBox 或其他替代管理协议。
:::
