# CSS610 系列手册

## 概述

SwOS Lite 是一款专为 MikroTik CSS610 系列交换机产品管理而设计的操作系统。CSS610 系列交换机仅支持 SwOS Lite 操作系统。

与 CSS3xx 系列交换机相比，主要区别如下：

- 不支持独立 VLAN 学习（Independent VLAN Learning）
- 不支持 "enabled" VLAN 模式
- 不支持 ACL 速率限制
- 支持端口出口速率限制

---

## CSS610 系列功能特性

| 特性 | 描述 |
| --- | --- |
| **转发** | 全线速无阻塞交换，主机表中最多支持 16k 条 MAC 条目，转发数据库仅基于 SVL 工作，支持端口隔离，支持巨帧 - 10218 字节 |
| **生成树协议** | 支持 RSTP |
| **链路聚合** | 支持 802.3ad LACP 组，支持静态链路聚合组，最多支持 16 个链路聚合组，每组最多 8 个成员端口，硬件自动故障切换和负载均衡 |
| **组播转发** | 支持 IGMP Snooping，支持未知组播过滤 |
| **VLAN** | 完全兼容 IEEE802.1Q，基于端口的 VLAN，最多支持 250 条 VLAN 条目（受 SwOS 限制），支持 VLAN 过滤 |
| **安全** | 端口锁定，广播风暴控制，DHCP 与 PPPoE Snooping |
| **服务质量（QoS）** | 入口流量限制，出口流量限制 |
| **访问控制列表** | 入口 ACL 表，最多支持 32 条 ACL 规则（受 SwOS 限制），基于端口、L2、L3、L4 协议头字段进行分类，ACL 操作包括过滤、转发和修改协议头字段 |

SwOS 配置工具中按钮的说明：

- **Append** - 在列表末尾添加新条目
- **Apply All** - 应用当前配置更改
- **Cut** - 从列表中移除条目
- **Clear** - 重置条目的属性
- **Discard Changes** - 丢弃未保存的配置
- **Insert** - 在列表中（当前条目之前）添加新条目
- **Sort** - 按 VLAN-ID 对 VLAN 表排序；按 MAC 地址对主机表排序
- **Change Password** - 更改交换机密码
- **Logout** - 从当前交换机注销
- **Reboot** - 重启交换机
- **Reset Configuration** - 将配置重置为出厂默认值
- **Choose File** - 浏览升级或备份文件
- **Upgrade** - 使用所选文件升级交换机固件
- **Download & Upgrade** - 自动尝试下载并升级固件，运行 Web 浏览器的 PC 需要能够访问互联网
- **Restore Backup** - 使用所选备份文件恢复交换机
- **Save Backup** - 生成并下载交换机的备份文件

## 端口隔离

端口隔离表允许或限制特定端口之间的流量转发。默认情况下，所有可用的交换芯片端口都可以与任何其他端口通信——不使用隔离。当复选框被启用/勾选时，您允许流量从该端口转发到被勾选的端口。以下是一些端口隔离示例。

![SwOS Isolated Groups](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css610-09.webp)

在某些场景中，您可能需要将一组设备与其他组隔离。在此示例中，**Port1-Port5** 上的设备无法与 **Port6-Port10** 上的设备通信，反之亦然。

![SwOS Private VLAN](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css610-10.webp)

在某些场景中，您可能需要将所有流量转发到上行链路端口，同时所有其他端口彼此隔离。这种设置称为 **Private VLAN** 配置。交换机将仅将所有以太网帧转发到上行链路 **Port1**，而上行链路可以访问所有其他端口。

![SwO isolation example3](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css610-11.webp)

单独隔离的 **Port1**（例如用于管理目的）——它无法与任何其他端口发送或接收流量。

> **注意：** 可以通过勾选一个复选框然后水平拖动（点击并拖动）来同时勾选/取消勾选多个复选框。

> **注意：** (R)STP 仅在 Private VLAN 设置中才能正常工作。在具有多个隔离交换机组的设置中，(R)STP 可能无法正确接收 BPDU，因此可能无法检测网络环路。

## LAG

支持兼容 IEEE 802.3ad (LACP) 的链路聚合，以及静态链路聚合，以确保仅基于 Layer2 哈希的故障切换和负载均衡。最多支持 16 个链路聚合组，每组最多 8 个端口。每个单独端口可以配置为 Passive LACP、Active LACP 或 Static LAG 端口。

| 属性 | 描述 |
| --- | --- |
| **Mode** *(默认值：passive)* | 指定端口上的 LACP 数据包交换模式或 Static LAG 模式：`Passive` - 将端口置于侦听状态，仅当对端端口使用 active LACP 模式时才使用 LACP`Active` - 无论对端端口模式如何，都优先启动 LACP`Static` - 将端口设置为 Static LAG 模式；需要为所有需要包含在同一静态 LAG 中的端口设置相同的 **Group** 设置 |
| **Group** | 指定静态 LAG 组 |
| **Trunk** *(只读)* | 表示端口所属的组编号 |
| **Partner** *(只读)* | 表示对端 MAC 地址；仅当端口包含在 LACP 中时可用 |

## 转发

Forwarding 选项卡提供交换机端口之间的高级转发选项、端口锁定、端口镜像、带宽限制和广播风暴控制功能。

![Swos forw css610](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css610-12.webp)

| 属性 | 描述 |
| --- | --- |
| **Port Lock** | `Port Lock` - 启用或禁用此端口上的 MAC 地址学习。启用后，将限制 MAC 地址学习，应配置静态 MAC 地址。任何接收到的源 MAC 地址未知的帧将被丢弃`Lock On First` - 允许从接收到的第一个帧学习源 MAC 地址；此属性应与 `Port Lock` 一起使用。每次接口状态变化时，第一个 MAC 地址的学习将重置 |
| **Port Mirroring** | `Mirror Ingress` - 进入此端口的流量是否必须被复制并转发到镜像目标端口`Mirror Egress` - 离开此端口的流量是否必须被复制并转发到镜像目标端口`Mirror To` - 镜像目标端口 |
| **Broadcast Storm Control** | `Storm Rate` - 限制接口传输的广播数据包数量。速率以比特每秒（bps）为单位`Include Unknown Unicast` - 将主机表中没有条目的单播数据包包含在 `Storm Rate` 限制中 |
| **Multicast Flood Control** | `Flood Unknown Multicast` - 更改交换机端口上的组播泛洪选项；仅控制出口流量。启用后，桥接允许将组播数据包泛洪到指定交换机端口；禁用后，限制组播流量被泛洪。此设置影响所有组播流量，包括非 IP、IPv4、IPv6 和链路本地组播范围（例如 224.0.0.0/24 和 ff02::1） |
| **Bandwidth Limit** | `Ingress Rate` - 限制进入此端口的流量（bps）`Egress Rate` - 限制离开此端口的流量（bps） |

> **注意：** 可以按端口限制入口/出口流量。入口流量使用 policer，出口流量使用 shaper。入口 policer 通过丢包来控制接收流量——超过定义限制的所有数据包将被丢弃。这可能会影响终端主机的 TCP 拥塞控制机制，实际达到的带宽可能低于定义值。出口 shaper 尝试对超过限制的数据包进行排队而不是丢弃。最终，当输出队列满时也会丢弃数据包；但是，它应该能更好地利用定义的吞吐量。

## RSTP

RSTP 菜单中提供按端口和全局的 RSTP 配置与监控。

![Swos rstp css326](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css610-13.webp)

| 属性 | 描述 |
| --- | --- |
| **Bridge Priority (hex)** | 用于根桥选择的 RSTP 桥优先级 |
| **Port Cost Mode** | 根据链路速率自动检测 RSTP 端口开销的两种方法。`short`：40G - 1；10G - 2；1G - 4；100M - 10；10M - 100`long`：40G - 500；10G - 2000；1G - 20000；100M - 200000；10M - 2000000 |
| **Forward Reserved Multicast** | 是否转发 **01:80:C2:00:00:0x** 范围内的 IEEE 保留组播 MAC 地址。符合 R/M/STP 标准的交换机应避免转发这些数据包。如果启用此设置，SwOS 将转发保留的组播 MAC 数据包并禁用 RSTP：- 交换机将不处理接收到的 BPDU（桥协议数据单元）- 也不会发送自己的 BPDU- Bridge Priority 和按端口的 RSTP 配置设置将不再生效。启用保留 MAC 地址转发可能会影响依赖这些地址的某些协议。建议仅在绝对必要时启用转发，例如在透明桥接设置中（如扩展长链路、将桥接用作媒体转换器或进行网络分析）。值得注意的 MAC 地址和协议示例（由 RouterOS 使用）：`01:80:C2:00:00:00` - 生成树协议（STP）`01:80:C2:00:00:01` - 以太网流量控制`01:80:C2:00:00:02` - 链路聚合控制协议（LACP）`01:80:C2:00:00:03` - Dot1x 客户端和服务器`01:80:C2:00:00:08` - 生成树协议（用于 802.1ad 桥接，使用 `ether-type=0x88a8`）`01:80:C2:00:00:0D` - 多 VLAN 注册协议（用于 802.1ad 桥接，使用 `ether-type=0x88a8`）`01:80:C2:00:00:0E` - 链路层发现协议、多机箱链路聚合组和精确时间协议流量控制 MAC 地址 `01:80:C2:00:00:01` 是一个例外——SwOS 不会转发它。 |
| **Root Bridge** | 网络中选定的根桥的优先级和 MAC 地址（只读） |
| **RSTP** | 在此端口上启用或禁用 STP/RSTP 功能 |
| **Mode** | 显示特定端口上的 STP/RSTP 功能模式（只读）：`RSTP``STP` |
| **Role** | 显示特定端口的角色（只读）：`root` - 面向根桥的端口，将用于与根桥之间的流量转发`alternate` - 面向根桥的端口，但不转发流量（根端口的备份）`backup` - 背向根桥的端口，但不转发流量（非根端口的备份）`designated` - 背向根桥的端口，将转发流量`disabled` - 不严格属于 STP 一部分的端口（RSTP 功能已禁用） |
| **Root Path Cost** | 显示面向根桥的端口的根路径开销（只读） |
| **Type** | `edge` - 不应接收任何 BPDU 的端口，应连接到终端设备（只读）`point-to-point` - 在全双工链路上运行的端口，可以是 STP 的一部分并以转发状态运行（只读） |
| **State** | 显示每个端口的状态（只读）：`forwarding` - 端口参与流量转发并学习 MAC 地址，接收 BPDU`discarding` - 端口不参与流量转发且不学习 MAC 地址，接收 BPDU`learning` - 端口不参与流量转发但学习 MAC 地址 |

## VLAN 和 VLANs

交换机端口的 VLAN 配置。

![Swos vlan css610](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css610-17.webp)

| 属性 | 描述 |
| --- | --- |
| **VLAN Mode** (*disabled \| optional \| strict*；默认值：**optional**) | VLAN 过滤模式；这些选项与出口端口相关（strict 模式除外）。`disabled` - 不使用 VLAN 表。交换机在出口端口丢弃带有 VLAN 标签的数据包。如果数据包带有 VLAN 标签且 VLAN ID 与出口端口上的 `Default VLAN ID` 匹配，则在 `VLAN Receive=any` 时，交换机将移除 VLAN 标签并转发数据包。`optional` - 禁用 VLAN 过滤。将带有 VLAN 表中不存在的 VLAN 标签 ID 的数据包视为无 VLAN 标签的数据包处理。`strict` - 启用 VLAN 过滤并附加入口过滤，检查入口端口是否为 VLAN 表中接收到的 VLAN ID 的成员。在入口端口上接收到的 VLAN ID 与 VLAN 表不匹配的数据包将被丢弃。必须为接入端口指定 Default VLAN ID，因为它将用于为特定端口的入口流量打标签和出口流量去标签。 |
| **VLAN Receive** (*any \| only tagged \| only untagged*；默认值：**optional**) | 基于 VLAN 标签存在性的接收流量过滤。`any` - 允许特定端口上的带标签和不带标签的数据包`only tagged` - 仅允许带有 VLAN 标签的数据包。"Default VLAN ID" 将不起作用，因为它仅适用于不带标签的流量`only untagged` - 仅允许不带 VLAN 标签的数据包 |
| **Default VLAN ID** (*整数：1..4095*；默认值：**1**) | 交换机将接收到的未标记数据包放入 "Default VLAN ID" VLAN 中。仅对未标记流量生效，且当 **VLAN Receive** 设置为 "any" 或 "only untagged" 时生效。不适用于带标签的流量。此参数通常用于为接入端口分配特定 VLAN。如果数据包的 VLAN ID 与 Default VLAN ID 匹配，也用于对出口流量进行去标签。 |
| **Force VLAN ID** (*yes \| no*；默认值：**no**) | 将 `Default VLAN ID` 值分配给所有入口流量（带标签和不带标签）。在所有 VLAN 模式下均生效。如果端口接收到带标签的流量且 `Default VLAN ID` 设置为 1，则启用此参数后，出口流量将被去标签。 |

交换机端口的 VLAN 成员配置。

![Swos vlans css610](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css610-18.webp)

| 属性 | 描述 |
| --- | --- |
| **VLAN ID** (*整数：1..4095*；默认值：**0**) | 要分配端口的 VLAN ID |
| **IGMP Snooping** (*yes \| no*；默认值：**no**) | 在定义的 VLAN 上启用或禁用 IGMP Snooping。启用后，交换机将侦听来自定义 VLAN 的 IGMP Join 和 Leave 请求，仅将流量转发到已从定义 VLAN 发送 IGMP 成员请求的端口。禁用后，交换机将向所有 VLAN 成员端口泛洪组播流量。 |
| **Members** (*端口*；默认值：**none**) | 允许在定义的 VLAN 上转发流量的端口组 |

### VLAN 配置示例

#### Trunk 和接入端口

![Access ports](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css610-19.webp)

1. 在 VLANs 菜单中添加 VLAN 条目并指定端口成员。

![Css610 vlans](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css610-20.webp)

1. 在 VLAN 菜单中为计划的接入端口（未标记）配置 Default VLAN ID，选择正确的 VLAN Receive 设置（Port2 仅带标签，Port6-8 仅未标记），并启用 strict VLAN 过滤以确保仅允许的 VLAN 可以通过端口。

![Css610 vlan](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css610-21.webp)

#### Trunk 和混合端口

![Hybrid ports](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css610-22.webp)

1. 在 VLANs 菜单中添加 VLAN 条目并指定端口成员。

![Css610 vlans hybrid](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css610-23.webp)

1. 在 VLAN 菜单中为计划的混合端口（用于未标记 VLAN）配置 Default VLAN ID，选择正确的 VLAN Receive 设置（Port2 仅带标签，Port6-8 any），并启用 strict VLAN 过滤以确保仅允许的 VLAN 可以通过端口。

![Css610 vlan hybrid](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css610-24.webp)

#### 管理访问

在此示例中，将创建 VLAN 200 上的交换机管理访问。配置方案与 "**Trunk 和接入端口**" 相同，步骤 **1.、2.** 完全一致。额外的 **第 3** 步需要在 System 菜单中指定管理 VLAN ID。应用配置后，交换机将仅响应 Port2 上带标签的 VLAN 200 数据包和 Port6 上未标记的数据包。DHCP 客户端也将在指定的 VLAN ID 中工作。

![Css610 system vlan](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css610-25.webp)

> **警告：** 如果 VLAN 设置配置不正确，更改管理 VLAN 可能会完全禁用对交换机管理的访问。在更改此设置之前请保存配置备份，如果管理访问丢失，请使用 [重置和重新安装](#reset-and-reinstall)。

## Hosts

此表表示动态学习的 MAC 地址到端口映射条目。它可以包含两种条目：动态和静态。动态条目自动添加——这也称为学习过程：当交换机从某个端口接收到数据包时，它将数据包的源 MAC 地址和接收该数据包的端口添加到主机表中，因此当数据包到达时，如果目标 MAC 地址已知，交换机就知道应该将数据包转发到哪个端口。如果目标 MAC 地址不在主机表中，则会将数据包转发到组中的所有端口。动态条目大约需要 5 分钟超时。

如果已存在相同 MAC 地址的动态条目，静态条目将取代动态条目。添加静态条目还可以访问更多功能。

![Swos shost css610](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css610-26.webp)

**静态主机属性**

| 属性 | 描述 |
| --- | --- |
| **Ports** | 数据包应转发到的端口 |
| **MAC** | MAC 地址 |

**动态主机属性（只读）**

| 属性 | 描述 |
| --- | --- |
| **Port** | 数据包应转发到的端口 |
| **MAC** | 学习到的 MAC 地址 |

## IGMP Snooping

## SNMP

SwOS 支持 SNMP v1 和 v2c（响应 GetRequest、GetNextRequest 和 GetBulkRequest），并使用 IF-MIB、SNMPv2-MIB、BRIDGE-MIB 和 MIKROTIK-MIB（仅用于健康、PoE-out 和 SFP 诊断）。不支持 SNMP trap 和写入 SwOS 配置。

可用的 SNMP 数据：

- 系统信息
- 系统运行时间
- 端口状态
- 接口统计信息
- 主机表信息

![Swos snmp2 1](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css610-30.webp)

| 属性 | 描述 |
| --- | --- |
| **Enabled** | 启用或禁用 SNMP 服务 |
| **Community** | SNMP 团体名称 |
| **Contact Info** | NMS 的联系信息 |
| **Location** | NMS 的位置信息 |

## ACL 和 ACL Stats 选项卡

访问控制列表（ACL）规则表是一个非常强大的工具，允许基于 L2、L3 和 L4 协议头字段条件进行线速数据包过滤、转发和 VLAN 标记。每条规则包含条件部分和操作部分。

![CSS610 ACL table](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css610-31.webp)

**条件部分参数**

| 属性 | 描述 |
| --- | --- |
| **From** | 数据包进入的端口 |
| **MAC Src** | 源 MAC 地址和掩码 |
| **MAC Dst** | 目标 MAC 地址和掩码 |
| **Ethertype** | 以太网帧负载中封装的协议 |
| **VLAN** | VLAN 头存在性：`any` / `present` / `not present` |
| **VLAN ID** | VLAN 标签 ID |
| **Priority** | VLAN 标签中的优先级 |
| **IP Src** (IP/网络掩码:端口) | 源 IPv4 地址、网络掩码和 L4 端口号 |
| **IP Dst** (IP/网络掩码:端口) | 目标 IPv4 地址、网络掩码和 L4 端口号 |
| **Protocol** *(整数)* | IP 协议 |
| **DSCP** | IP DSCP 字段 |

**操作部分参数**

| 属性 | 描述 |
| --- | --- |
| **Account as** | 选择匹配的数据包将被计数的计数器 |
| **Redirect To** | 强制新数据包的目标端口 |
| **Mirror** | 克隆数据包并将其发送到镜像目标端口 |
| **Drop** | 丢弃数据包 |
| **Set VLAN ID** | 如果存在 VLAN 标签，更改 VLAN 标签 ID |
| **Priority** | 如果存在 VLAN 标签，更改 VLAN 标签优先级位 |
| **DSCP** | 更改 IP DSCP 字段 |

每条 ACL 规则可以分配给特定的计数器，匹配的数据包将被计数。

![Css610 acl stats](https://manual.mikrotik.com/docs/bridging-and-switching/swos/img/css610-32.webp)

## 重置和重新安装

CSS610 具有内置的备份 SwOS 固件，在标准固件损坏或升级失败时可以加载：

- 在设备启动时按住 Reset 按钮几秒钟将重置配置并加载备份固件。
- 加载备份固件后，可以使用 Web 浏览器连接到 192.168.88.1（或从 DHCP 服务器租用的地址）并安装新的 SwOS 固件。
