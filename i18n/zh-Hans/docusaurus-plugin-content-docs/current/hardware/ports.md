# 端口

> 本文档介绍 MikroTik RouterOS 的端口配置选项，涵盖用于初始设置的串行端口和 USB 端口、3G 调制解调器连接、通过 RFC 2217 进行远程访问，以及波特率、流控制和停止位等详细端口属性。

# 端口

## 概述

路由器提供了多种利用其端口的选项。最常见的用途是串行端口，用于安装后对 RouterOS 进行初始配置。默认情况下，serial0 由串行终端使用。

串行端口和 USB 端口还可用于：

- 连接 3G 调制解调器。
- 通过串行电缆连接到另一台设备。
- 远程访问连接到串行电缆的设备。

## 常规

**子菜单：** `/port`

此菜单显示路由器上所有可用的串行和 USB 端口，并允许您配置端口参数，如波特率、流控制和其他设置。

以下示例显示了 LtAP 设备上的默认端口配置：

```ros
[admin@LtAP] > /port/print                 
Columns: DEVICE, NAME, CHANNELS, USED-BY, BAUD-RATE
# DEVICE  NAME     CHANNELS  USED-BY                                     BAUD-RATE
0         serial0         1  Serial Console(#0)                          auto     
1         gps             1  GPS(#0)                                     115200   
```

:::warning
端口列表由 RouterOS 自动维护。

:::

## 属性

| 属性 | 说明 |
| :-- | :-- |
| **baud-rate** (*整数 \| auto*；默认值：**auto**) | 端口使用的波特率（速度）。如果设置为 **auto**，则 RouterOS 会尝试自动检测波特率。 |
| **data-bits** (*7 \| 8*；默认值：) | 每个字符中的数据位数。7 - 真正的 ASCII 码；8 - 任意数据（与字节大小匹配） |
| **dtr** (*on \| off*；默认值：) | 是否启用用于流控制的 RS-232 DTR 信号电路。 |
| **flow-control** (*hardware \| none \| xon-xoff*；默认值：) | 用于暂停和恢复数据传输的流控制方法。 |
| **name** (*字符串*；默认值：) | 端口名称。 |
| **parity** (*even \| none \| odd*；默认值：) | 错误检测方法。如果启用，则会发送一个额外的位来检测通信错误。在大多数情况下，奇偶校验设置为 **none**，错误由通信协议处理。 |
| **rts** (*on \| off*；默认值：) | 是否启用用于流控制的 RS-232 RTS 信号电路。 |
| **stop-bits** (*1 \| 2*；默认值：) | 每个字符后发送的停止位。电子设备通常使用 1 个停止位。 |

### 只读属性

| 属性 | 说明 |
| :-- | :-- |
| **channels** (*整数*) | 端口支持的通道数。 |
| **inactive** (*yes \| no*) | 显示当前端口状态，**inactive=yes** - 端口之前连接的设备当前不存在 |
| **line-state** () |  |
| **used-by** (*字符串*) | 显示当前正在使用端口和通道 (#) 的对象。例如，默认情况下 **Serial0** 由串行控制台使用。 |

## 远程访问

**子菜单：** `/port/remote-access`

远程访问功能允许您连接到位于路由器后方、通过 COM 端口通信的串行设备。RouterOS 利用 RFC 2217，可以通过 TCP 连接与串行设备进行数据传输。

在 RouterOS 上启用远程访问非常简单：

```ros
/port/remote-access/add port=serial0 protocol=rfc2217 tcp-port=9999
```

:::warning
默认情况下，serial0 由串行终端使用。必须先释放该端口，然后才能将其用于远程访问或其他服务。

:::

## 属性

| 属性 | 说明 |
| :-- | :-- |
| **allowed-addresses** (*IP 地址范围*；默认值：**0.0.0.0/0**) | 允许远程访问端口的 IP 地址范围。 |
| **channel** (*整数 [0..4294967295]*；默认值：**0**) | 将使用的端口通道。如果端口只有一个通道，则通道号应始终为 **0**。 |
| **disabled** (*yes \| no*；默认值：**no**) |  |
| **local-address** (*IP 地址*；默认值：) | 用作源地址的 IP 地址。 |
| **log-file** (*字符串*；默认值：**""**) | 用于记录通信内容的文件名。默认情况下，日志记录处于禁用状态。 |
| **port** (*字符串*；默认值：) | 端口列表中的端口名称。 |
| **protocol** (*raw \| rfc2217*；默认值：**rfc2217**) | RFC 2217 定义了一种通过 TCP 与串行设备传输数据的协议。如果设置为 **raw**，则数据将原样发送到串行端口。 |
| **tcp-port** (*整数 [0..65535]*；默认值：**0**) | 用于监听传入连接的 TCP 端口。 |

## 只读属性

| 属性 | 说明 |
| :-- | :-- |
| **active** (*yes \| no*) | 远程访问是否处于活动状态并准备好接受连接。 |
| **busy** (*yes \| no*) | 端口当前是否处于忙碌状态。 |
| **inactive** (*yes \| no*) |  |
| **logging-active** (*yes \| no*) | 当前是否正在将日志记录到文件 |
| **remote-address** (*IP 地址*) | 当前连接的远程位置的 IP 地址。 |
