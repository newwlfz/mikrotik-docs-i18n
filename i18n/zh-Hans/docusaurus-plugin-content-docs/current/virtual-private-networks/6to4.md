# 6to4

> 本文档介绍 MikroTik RouterOS 6to4 接口的配置，说明如何在不显式配置隧道的情况下，通过 IPv4 网络传输 IPv6 数据包。文中详细介绍了 MTU、keepalive 设置及 IPsec 集成等属性，并提供了建立 6to4 隧道的配置示例。

# 6to4

6to4 是一种特殊机制，允许 IPv6 数据包在不显式配置隧道接口的情况下，通过 IPv4 网络进行传输。这对于在不支持 IPv6 的网络上连接两个或多个 IPv6 网络尤为有用。6to4 机制有两种不同的工作方式。如果未配置 *remote-address*，当 IPv6 数据包的前 16 位为 *2002* 时，路由器将直接通过 IPv4 封装并发送该数据包，并将接下来的 32 位作为目标地址（IPv4 地址转换为十六进制）。另一种情况下，IPv6 数据包将直接发送到指定的 IPv4 *remote-address*。
**子菜单：** `/interface/6to4`

## 属性说明

| 属性 | 说明 |
| :-- | :-- |
| **clamp-tcp-mss** (*yes \| no*；默认值：**yes**) | 控制是否修改接收到的 TCP SYN 数据包的 MSS 大小。启用时，如果当前 MSS 大小超过隧道接口 MTU（考虑 TCP/IP 开销），路由器将修改接收到的 TCP SYN 数据包的 MSS 大小。接收到的封装数据包仍包含原始 MSS，仅在解封装后 MSS 才会被修改。 |
| **comment** (*string*；默认值：) | 接口的简短描述。 |
| **disabled** (*yes \| no*；默认值：**no**) | 项目是否被禁用。 |
| **dont-fragment** (*inherit \| no*；默认值：**no**) | 是否在相关数据包中包含 DF 位：*no* - 需要时进行分片，*inherit* - 使用原始数据包的“不分片”标志。（若未设置“不分片”：inherit - 数据包可能被分片）。 |
| **dscp** (*integer: 0-63*；默认值：**inherit**) | 数据包的 DSCP 值。Inherited 选项表示 DSCP 值将从待封装的数据包中继承。 |
| **ipsec-secret** (*string*；默认值：) *[敏感参数](../getting-started/configuration-management/list-of-menus-with-sensitive-parameters.md)* | 当指定了密钥时，路由器会向 remote-address 添加一个动态 IPsec 对等体，使用预共享密钥和策略（默认情况下 phase2 使用 sha1/aes128cbc）。 |
| **keepalive** (*integer[/time],integer 0..4294967295*；默认值：**0,0**) | 隧道 keepalive 参数设置时间间隔，在此间隔内即使隧道远端宕机，隧道运行标志仍将保持。如果配置的时间和重试次数失败，接口运行标志将被移除。参数格式如下：`KeepaliveInterval,KeepaliveRetries`，其中 `KeepaliveInterval` 是时间间隔，`KeepaliveRetries` 是重试次数。默认情况下 keepalive 被禁用（0 秒，0 次重试）。 |
| **local-address** (*IP*；默认值：) | 数据包的源地址，为路由器本地地址。 |
| **mtu** (*integer*；默认值：**auto**) | 第三层最大传输单元。 |
| **name** (*string*；默认值：) | 接口名称。 |
| **remote-address** (*IP*；默认值：) | 6to4 隧道远端的 IP 地址。如果未指定，IPv4 地址将从 2002::/16 网关地址中派生。 |

## 配置示例

### 简单的 6to4 隧道封装（当前不可用）

![](https://manual.mikrotik.com/docs/virtual-private-networks/img/6to4-01.webp)

可以通过利用 2002::/16 分配的地址空间，简单地在 IPv4 网络上路由 IPv6 数据包。所有 6to4 节点必须具有可达的 IPv4 地址——如果通过互联网运行此设置，所有 IPv4 地址必须是公网地址。

#### R1 配置

创建 6to4 隧道接口：

```ros
/interface/6to4
add name=6to4-tunnel1
```

分配一个 IPv6 地址，前 16 位为 '2002'，接下来的 32 位为十六进制格式的 IPv4 地址。例如，如果路由器的 IP 地址是 10.0.1.1，则 IPv6 地址为 2002:A00:101:：

```ros
/ipv6/address
add address=2002:a00:101::/128 advertise=no interface=6to4-tunnel1
```

通过 6to4-tunnel 接口添加一条到专门分配的 6to4 隧道范围的路由。

```ros
/ipv6/route
add dst-address=2002::/16 gateway=6to4-tunnel1
```

#### R2 配置

创建 6to4 隧道接口：

```ros
/interface/6to4
add name=6to4-tunnel1
```

分配一个与 R1 相同原则生成的 IPv6 地址。在此情况下，10.0.2.1 转换为 2002:A00:201:：

```ros
/ipv6/address
add address=2002:a00:201::/128 advertise=no interface=6to4-tunnel1
```

此侧同样需要 6to4 路由。

```ros
/ipv6/route
add dst-address=2002::/16 gateway=6to4-tunnel1
```

#### 测试

配置完两台设备后，如果地址生成正确，应能 ping 通 IPv6 地址。

从 R1 执行：

```ros
/ping 2002:a00:201::
```

### Hurricane Electric 隧道代理示例

以下示例将展示如何通过 6to4 隧道，在 RouterOS 设备上通过 IPv4 网络获得 IPv6 连接。

要创建隧道，您必须拥有公网 IPv4 地址，并允许来自 Tunnel Broker IPv4 服务器的 ping。

当您使用 [Hurricane Electric Tunnel Broker](https://tunnelbroker.net) 创建隧道时，您将获得一个路由的 /64 IPv6 前缀以及设置隧道所需的附加信息。

*![](https://manual.mikrotik.com/docs/virtual-private-networks/img/6to4-02.webp)*

*本示例假定您的公网 IPv4 地址为 194.105.56.170*

Hurricane Electric 在“示例配置”部分提供了适用于 RouterOS 的现成命令：

```ros
/interface/6to4
add comment="Hurricane Electric IPv6 Tunnel Broker" disabled=no local-address=194.105.56.170 mtu=1280 name=sit1 remote-address=216.66.80.90
/ipv6/route
add comment="" disabled=no distance=1 dst-address=2000::/3 gateway=2001:470:27:37e::1 scope=30 target-scope=10
/ipv6/address
add address=2001:470:27:37e::2/64 advertise=no disabled=no eui-64=no interface=sit1
```

这些命令将设置隧道本身——路由器将能够连接到 IPv6 主机，但终端用户设备（计算机、平板电脑、手机）尚不具备 IPv6 连接。

要为您的客户端分配 IPv6 地址，您必须将路由的 IPv6 前缀添加到内部接口（默认为 bridge-local）。

```ros
/ipv6/address/add address=2001:470:28:37e:: interface=bridge-local advertise=yes
```

通过网络发现启用 DNS 服务器通告

```ros
/ipv6/nd/set [ find default=yes ] advertise-dns=yes
```

最后添加 IPv6 DNS 服务器（这些是 Google 公共 DNS 服务器，您也可以使用 Hurricane Electric 提供的服务器——2001:470:20::2）。

```ros
/ip/dns/set allow-remote-requests=yes servers=2001:4860:4860::8888,2001:4860:4860::8844
```

之后在您的设备上启用 IPv6，您应该就能获得 IPv6 连接。可以使用 [https://test-ipv6.com](https://test-ipv6.com/) 测试 IPv6 连接。
