# 路由区分符与路由目标

> 路由区分符（RD）为客户地址添加唯一前缀，用于区分VRF，而路由目标则控制实例之间的BGP路由信息交换。

# 路由区分符与路由目标

## 路由区分符

路由区分符是添加到客户目标地址上的唯一前缀，用于区分可能看起来相同的通告。例如，重叠的VRF子网可以通过唯一的路由区分符加以区分。

RD是一个64位整数，分为三个部分：

- 类型（始终为2字节）。
- 管理子字段。
- 值或服务提供商子字段。

目前定义了三种格式类型。

| **2字节**    | 2字节       | 4字节        |          |
|:--|:--|:--|:--|
| **类型0**    | ASN        | 4字节值      |          |
| **类型1**    | 4字节IP    | 2字节值      |          |
| **类型2**    | 4字节ASN   | 2字节值      |          |

## 路由目标

路由目标是一种BGP扩展团体，用于控制路由实例之间路由信息的导入和导出。
