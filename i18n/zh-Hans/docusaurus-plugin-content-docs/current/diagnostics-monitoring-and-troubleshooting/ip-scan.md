# IP 扫描

> RouterOS 中的 IP 扫描工具用于扫描网络中的活动设备，收集 IP 地址、MAC 地址、响应时间、DNS 名称、SNMP 字符串和 NET-BIOS 名称。它可以通过 IPv4 前缀或接口监听进行扫描，并警告避免冲突设置。

# IP 扫描

IP 扫描工具允许用户根据某个网络前缀或通过设置接口进行监听来扫描网络。无论采用哪种方式，该工具都会从网络中收集特定数据：

- address - 网络设备的 IP 地址。
- mac-address - 网络设备的 MAC 地址。
- time - 发现网络设备时的响应时间。
- DNS - 网络设备的 DNS 名称。
- SNMP - 设备的 SNMP 名称。
- NET-BIOS - 设备的 NET-BIOS 名称（如果设备通告了该名称）。

使用 IP 扫描工具时，用户必须选择要扫描的目标：

- 特定的 IPv4 前缀 - 该工具将尝试扫描所有设置的 IP 地址或地址范围。
- 路由器的接口 - 该工具将尝试监听“经过”的数据包，并在发现内容时尝试汇总结果。

:::danger
可以同时设置两者，但这样可能会导致结果不明确！
:::

## 快速示例

`/tool/ip-scan` 工具是用户发现特定 IP 范围内活动主机的必备诊断工具。它对于识别未授权设备、验证 IP 地址分配或在文档缺失时绘制网段拓扑特别有用。通过发送 ICMP 和 ARP 请求，它可以实时概览可达地址、其关联的 MAC 地址，甚至兼容设备的 SNMP 标识字符串。

该工具在初始站点审计或排查动态 DHCP 环境中的连接问题时经常使用。通过扫描本地子网，您可以快速将物理硬件与逻辑 IP 地址关联起来，以检测 IP 冲突或非法接入点。这种可见性对于维护网络完整性以及确保所有已连接的基础设施符合预期的部署拓扑至关重要。

在以下示例中，我们将扫描 10.155.126.0/24 网络上的设备：
