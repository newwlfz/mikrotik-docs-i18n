# 注意

> RouterOS 中的系统备注功能允许用户分配在登录时显示的自定义文本消息，并可选择在 CLI 或 FTP 登录时显示，通过 `/system/note` 菜单或上传文件来配置其内容。

# 注意

### 概述

**子菜单：** `/system/note`

系统备注功能允许您分配任意文本备注或消息，这些内容将在每次登录时于横幅之后立即显示。例如，您可以通过这种方式在系统管理员之间发布警告，或描述该特定路由器的实际用途。要配置系统备注，您可以上传一个名为 **sys-note.txt** 的纯文本文件到路由器的 FTP 服务器，或者，也可以在此菜单中编辑设置。

### 属性

| 属性 | 说明 |
| :-- | :-- |
| **note** (*字符串*；默认值：) | 将显示的备注内容。 |
| **show-at-login** (*是 \| 否*；默认值：**是**) | 是否在每次登录时显示系统备注。 |
| **show-at-cli-login** (*是* \| *否*；默认值：**否**) | 是否在 telnet 登录提示符之前显示系统备注。 |

### 示例

可以使用内置文本编辑器（*`/system/note/edit` note*）添加多行备注，例如，为您的家用路由器添加 ASCII 艺术图：

```
/system/note/set note=
```
