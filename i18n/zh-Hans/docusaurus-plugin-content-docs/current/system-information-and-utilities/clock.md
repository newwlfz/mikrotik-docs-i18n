# 时钟

> 本页介绍 MikroTik RouterOS 的时钟配置，包括时区设置的自动检测与手动调整、GMT 偏移量、夏令时规则，以及关于内部时钟可靠性的警告。

# 时钟

RouterOS 使用 TZ 数据库中的数据。该数据库中的大多数时区均已包含，并具有相同的名称。由于路由器上的本地时间主要用于时间戳和基于时间的配置，而非历史日期计算，因此未包含过去年份的时区信息。目前，仅包含自 2005 年以来的信息。

以下设置可在 `/system/clock` 控制台路径以及 WinBox 窗口的“系统 > 时钟”中的“时间”选项卡中找到。

启动日期和时间默认为 **1970-01-02 00:00:00** [+|-]gmt-offset。

## 属性

| 属性 | 描述 |
| :-- | :-- |
| **time** (*HH:MM:SS*); | 其中 *HH* - 小时 00..23，*MM* - 分钟 00..59，*SS* - 秒 00..59。 |
| **date** (*YYYY-MM-DD*); | 其中 *YYYY* - 年份，1970..2037，*MM* - 月份，01..12，*DD* - 日期，01..31：**date** 和 **time** 显示路由器当前的本地时间。这些值可以使用 **set** 命令进行调整。但是，本地时间无法导出，也不会与其余配置一起存储。 |
| **time-zone-name** (*manual*，或时区名称；默认值：*manual*); | 时区名称。与 RouterOS 中的大多数文本值一样，此值区分大小写。特殊值 *manual* 应用手动配置的 GMT 偏移量，默认值为 *00:00*，且无夏令时。 |
| **time-zone-autodetect** (*yes* 或 *no*；默认值：yes); | 自 v6.27 起可用的功能。如果启用，时区将自动设置。 |

:::warning
在新安装的 RouterOS 以及配置重置后，time-zone-autodetect 默认启用。时区根据路由器的公共 IP 地址和我们的 Cloud 服务器数据库进行检测。自 RouterOS v6.43 起，您的设备将使用 cloud2.mikrotik.com 与 MikroTik 的 Cloud 服务器通信。旧版本将使用 cloud.mikrotik.com 与 MikroTik 的 Cloud 服务器通信。

**重要提示：** 请注意，路由器的内部 CPU 时钟并非精确计时操作的可靠时间源，因为其频率可能因电源管理、热条件以及硬件差异而变化，即使在相同型号之间也是如此。这种变化是正常的，不会影响路由器的正常性能。为了获得准确的时间，建议使用基于网络的时间同步，例如 NTP（网络时间协议）。
:::

配置

### 活动时区信息

- **dst-active** (*yes* 或 *no*；只读属性)：当当前时区的夏令时处于活动状态时，此属性的值为 *yes*。
- **gmt-offset** ([*+*|*-*]*HH:MM* - 以小时和分钟为单位的偏移量；只读属性)：这是系统当前使用的 GMT 偏移量值，在应用基本时区偏移量和活动夏令时偏移量之后得出。

### 手动时区配置

这些设置可在 `/system/clock/manual` 控制台路径以及 WinBox 窗口的“系统 > 时钟”中的“手动时区”选项卡中找到。这些设置仅在 **time-zone-name**=*manual* 时生效。只能手动配置一个夏令时时间段。

- **time-zone**、**dst-delta** ([*+*|*-*]*HH:MM* - 以小时和分钟为单位的时间偏移量，前导加号可选；默认值：*+00:00*)：当 DST 未激活时，使用 GMT 偏移量 **time-zone**。当 DST 激活时，使用 GMT 偏移量 **time-zone** + **dst-delta**。
- **dst-start**、**dst-end** (*YYYY-MM-DD HH:MM:SS* - 日期和时间，在 **set** 命令中可以省略日期或时间；默认值：*1970-01-01 00:00:00*)：DST 开始和结束的本地时间。
