# 接口列表

> RouterOS 中的接口列表允许定义接口集合，以便在各种配置中简化管理。主菜单显示预定义和自定义的接口列表，而成员子菜单则处理静态配置的成员。动态接口根据标志自动包含或排除，而桥接接口需要谨慎处理以避免意外行为。

# 接口列表

允许定义一组接口，以便在基于接口的不同配置部分（如邻居发现、防火墙、桥接和互联网检测）中更轻松地管理接口。

## 列表

**子菜单：** `/interface/list`

此菜单包含路由器上所有可用接口列表的信息。有四个预定义列表 - `all`（包含所有接口）、`none`（不包含任何接口）、`dynamic`（包含动态接口）和 `static`（包含静态接口）。也可以创建额外的接口列表。

:::info
动态接口是指具有“动态”标志的接口。任何没有动态标志的接口都将属于 `static` 接口列表。
:::

| 属性 | 描述 |
| :-- | :-- |
| **name** (*字符串*) | 接口列表的名称 |
| **include** (*字符串*) | 定义其成员被包含在该列表中的接口列表。可以添加多个列表，用逗号分隔 |
| **exclude** (*字符串*) | 定义其成员被排除在该列表之外的接口列表。可以添加多个列表，用逗号分隔 |

成员按以下顺序添加到接口列表中：

1. 包含的成员被添加到接口列表中。
2. 排除的成员从列表中移除。
3. 静态配置的成员被添加到列表中。

## 成员

**子菜单：** `/interface/list/member`

此子菜单包含每个接口列表中静态配置的接口成员的信息。请注意，通过 include 和 exclude 语句动态添加的接口不在此子菜单中显示。

| 属性 | 描述 |
| :-- | :-- |
| **interface** (*字符串*) | 接口的名称 |
| **list** (*字符串*) | 接口列表的名称 |

:::info
在处理桥接和列表时必须小心。将桥接添加为成员与添加其所有端口不同！将所有从属端口添加为成员也与添加桥接本身不同。这尤其可能影响邻居发现的功能。
:::
