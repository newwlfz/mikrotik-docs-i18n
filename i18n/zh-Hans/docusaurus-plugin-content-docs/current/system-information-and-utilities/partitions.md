# 分区

> RouterOS 允许在兼容设备上对 NAND 闪存进行重新分区，以支持多操作系统安装并具备自动回退功能，从而确保升级期间的系统可靠性。该功能最多支持 8 个分区，对存储容量有最低要求，并包含用于管理活动分区、克隆配置和恢复备份的命令。

# 分区

分区功能支持使用 NAND 闪存的 ARM、ARM64、MIPS、TILE 和 PowerPC RouterBOARD 设备。

RouterOS 允许对 NAND 闪存进行重新分区，从而实现：

- 在每个分区上独立安装 RouterOS。
- 指定主分区和回退分区的能力。

如果某个分区无法启动（由于升级失败、配置问题或软件错误），下一个分区将自动启动，提供回退机制。此功能充当交互式备份，允许您保留一个经过验证且可正常工作的安装，并仅在辅助分区上执行升级。

一旦确认新配置稳定，您可以使用“保存配置到”功能将其复制到其他分区。

:::warning
对 NAND 进行重新分区需要最新的 bootloader 版本
:::

#### 要求与限制

- 从 RouterOS 7.20beta2 开始，重新分区的最低存储容量为 128 MiB。
- 重新分区期间 RouterOS 分区的最小尺寸：60 MiB。
- 允许的最大分区数为 8。

对于本应隐藏“分区”菜单但之前已重新分区的设备：

- 将可以重新分区为单个分区。

- 重启后，“分区”菜单将被隐藏。

#### 示例

对于具有 128 MiB NAND 且之前有 4 个 32 MiB 分区（RouterOS 可容纳在 32 MiB 内）的设备，从 RouterOS 7.20beta2 开始升级后的行为如下：

- 它将像重新分区前一样，继续使用所有 4 个分区并拥有完整的分区选项。
- 如果进行重新分区，唯一可用的选项将是 1 个 128 MiB 或 2 个 64 MiB 分区，并且完整的分区功能将保持可用。

```ros
[admin@MikroTik] > /partitions/print
Flags: A - ACTIVE; R - RUNNING
Columns: NAME, FALLBACK-TO, VERSION, SIZE
# NAME FALL VERSION SIZE 
0 AR part0  next         RouterOS v7.18.2 2025-03-11 11:59:04  128MiB
```

:::warning
从 RouterOS 7.17 版本开始，您需要更新 [device-mode](./device-mode.md) 才能使用分区功能。
:::

## 命令

| 属性 | 描述 |
| :-- | :-- |
| **activate** (*分区*) | 将另一个分区指定为活动分区。此选项在设备模式中启用“partitions”设置后可用（自 RouterOS 7.17 起）。 |
| **repartition** (*整数*) | 将重启路由器并重新格式化 NAND，仅保留活动分区。 |
| **copy-to** (*分区*) | 将**正在运行**的操作系统及其配置克隆到指定分区。该分区上先前存储的数据将被擦除。 |
| **save-config-to** (*分区*) | 将**运行配置**克隆到指定分区。其他所有内容均不受影响。 |
| **restore-config-from** (*分区*) | 将配置从指定分区复制到**正在运行**的分区。 |

## 属性

| 属性 | 描述 |
| :-- | :-- |
| **name** (*字符串*; 默认值: ) | 分区名称 |
| **fallback-to** (*etherboot \| next \| 分区名称*; 默认值: **next**) | 如果活动分区启动失败时执行的操作：etherboot - 切换到 etherbootnext - 尝试下一个分区回退到指定分区 |

### 只读属性

| 属性 | 描述 |
| :-- | :-- |
| **active** (*是 \| 否*) | 分区是否为活动分区 |
| **running** (*是 \| 否*) | 当前正在运行的分区 |
| **size** (*整数[MiB]*) | 分区大小 |
| **version** (*字符串*) | 分区上当前安装的 RouterOS 版本 |
