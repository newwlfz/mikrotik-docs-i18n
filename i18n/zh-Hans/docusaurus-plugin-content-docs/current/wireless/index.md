# 无线

> 本节介绍 MikroTik RouterOS 无线配置，涵盖不同 CPU 类型和频段（2.4GHz、5GHz、60GHz）的软件包选择、家庭接入点和工业链路的使用场景，以及客户端数量和覆盖范围优化等注意事项。

# 无线

本节将介绍 802.11 无线协议的配置及最佳使用示例。

路由器的无线功能可以极大地提升家庭或办公网络的可用性，或为工业结构提供解决方案。对于缺乏经验的用户来说，选择合适的设备进行设置可能是一个难题。本指南旨在解释不同参数，并建议一种思考过程，以免在 MikroTik 路由器的众多选择中迷失方向。

### RouterOS 软件包类型

某些 MikroTik 设备可以根据所需功能和设备类型，在两种类型的 Wireless NPK 软件包（即无线驱动）之间进行选择。更多详细信息可在相应的文档部分中找到。CAPsMAN 功能包含在 routeros 捆绑包中，与 CPU 架构无关，且独立于无线驱动，即您可以在任何型号上运行 CAPsMAN。

简而言之：

- CAPsMAN 可以在任何 MikroTik 设备上运行。在大多数情况下，您可以同时运行新版和旧版 CAPsMAN（在 AX 路由器上同时运行时，内置网卡无法使用）。
- MIPS 类型设备无法选择驱动，仅支持旧版驱动。
- ARM CPU 802.11AC 无线设备可以选择无线驱动：`wireless.npk` 或 `wifi-qcom-ac.npk`。

### 频率

MikroTik 提供具有 3 个频段接口的路由器——2.4GHz、5GHz 和 60GHz。每个频段都有其自身的优势和使用场景。

#### 2.4GHz

如今，由于过度使用而被视为旧版，但它仍然是被最广泛支持的频段。如果您的无线客户端（如手机、笔记本电脑或其他设备）支持无线连接，那么它很可能支持此频段。即使是物联网设备也通常支持 2.4GHz 频段。由于频率较低，2.4GHz 频段能更好地穿透障碍物，因此其覆盖范围通常比 5GHz 设备更大，但其吞吐量（互联网速度）通常也较低。此外，它可能会受到来自其他 2.4GHz 无线设备的严重干扰（噪声），因为几乎每个家庭接入点都支持 2.4GHz 频段，并且它能很好地穿透墙壁和远距离传输，同时可供选择的频率也较少（3 个不重叠信道）。如果您有许多邻近的邻居（公寓、共享办公楼），2.4GHz 频段很可能会饱和，性能会降低。该频段也可用于工业链路。

#### 5GHz

通常，新款手机和笔记本电脑也支持 5GHz 频段。如果您的客户端设备和路由器支持 802.11ac（有时简称为“ac”），那么它将比 2.4GHz 频段更快。5GHz 频段有更多频率可供选择，但通常其覆盖范围也比 2.4GHz 频段小。如果您有新的客户端设备，您的网络将受益于 ac 路由器。5GHz 频段也常用于工业链路，因为其频率范围广。

#### 60GHz

目前，支持 60GHz 频段的客户端设备（手机、笔记本电脑）非常少。然而，它为工业链路提供了尖端解决方案。例如，如果您有 2 个点需要在长达 1500 米的距离内连接，您将获得 1 Gbps 的全双工链路。例如，MikroTik 的一款产品被称为 *Wireless Wire*，因为它提供与 1Gbps 有线连接相同的速度，但您需要清晰的视线才能建立链路。

### 使用场景

MikroTik 设备上的 RouterOS 软件提供了广泛且一致的配置可能性。RouterOS 软件允许您以多种方式使用 MikroTik 设备，例如，如果需要，“家庭接入点”设备可以轻松重新配置为充当客户端或形成点对点链路。“家庭 AP”只是默认配置，但可以更改为您想要的任何配置。话虽如此，最好还是将硬件用于其预期用途。

#### 面向手机和笔记本电脑的家庭 AP

在确定最适合您设置的选择之前，您应该回答一些问题，例如您想连接多少客户端、需要覆盖多大范围以及想要达到什么速度。

#### 客户端数量

更多连接的客户端意味着更高的延迟和更小的吞吐量。我们建议每个接口连接 20-50 个客户端以达到峰值性能，根据条件，客户端数量可以达到 100 个并且仍然稳定工作。如果客户端需要高吞吐量或数据流量对时间敏感，建议规划每个接入点更少的客户端。通常，选择更简单的接入点但部署得更密集是有益的。

#### 覆盖范围

无线连接的覆盖范围取决于许多条件。其中一些包括天线增益、路由器和客户端设备的发射功率、来自其他设备的干扰、障碍物（墙壁、金属物体）、路由器放置位置。需要注意的一个重要因素是，所有涉及的设备都会影响可达到的距离，这意味着无论您的 AP 多么强大和灵敏，小型手机都会受到其自身发射功率和灵敏度的限制。如果客户端设备是手机，单个设备无法覆盖大面积区域。通常，只能达到几百米，需要更多 AP 设备来覆盖更大的区域。

- **天线增益** 以 dBi 为单位，决定了波束的窄度。0 dBi（实际上不可能）的辐射方向图是球形的，1.5 dBi - 5 dBi 几乎向所有方向均匀辐射，但有一些凹陷和侧面信号会更强。> 9 dBi 具有明显的定向辐射方向图。具有更高天线增益的天线，如果放置得当，将在所需方向上传输得更远。
- **发射功率** 以 dBm 或 mW 为单位，决定了从无线接口发出的信号强度。移动设备通常具有较低的发射功率以节省电池电量。例如，即使手机报告接收信号强度良好，路由器也可能从手机接收到较弱的信号。

- **干扰** 来自其他设备会增加噪声基底，使路由器更难区分信号和噪声，因此信号必须更强，客户端必须更靠近接入点。同一频率的接入点占用相同的空中时间，从而降低吞吐量并增加延迟。

- 某些**物体**会降低（衰减）信号强度，而其他物体则会反射信号。通常，在建筑物内，您需要考虑墙壁及其厚度、地板、天花板、金属物体。玻璃和木材也会衰减信号。

- 接入点的**放置位置**也会影响覆盖范围。接入点不应被金属物体或表面覆盖，以便信号有空间传播。

#### 速度

如果速度很重要，那么您应该选择支持 802.11 ac 的 5GHz 无线路由器。

### 用于连接其他无线天线（CPE 到 AP）

通常需要连接两个或多个点，例如连接校园内的建筑物或将客户端家庭连接到网络，或建立长距离链路。MikroTik 在这些情况下也提供了解决方案。为了做出选择，您必须知道距离、是需要连接两个点（点对点 - PtP）还是多个点（点对多点 - PtMP），以及需要什么速度。

#### 距离

因为在这些情况下我们处理的是定向天线和远距离，您必须记住，对准和视线至关重要。对于长达 1500 米的小距离，我们建议使用 60 GHz 设备，这将提供稳定性和出色的速度。此外，在小距离内，具有小天线增益的 2.4 GHz 或 5 GHz 设备也完全可以胜任，尽管您不会获得像 60 GHz 设备那样的速度。对于更长的链路，应考虑天线增益和发射功率。更高的信号强度将允许更高的数据速率，这意味着更高的吞吐量。明智地选择您的频率，以避免与其他无线链路产生干扰。请记住，在城市中，即使在屋顶上方，也常常存在来自邻近 2.4 GHz 和 5 GHz 链路的干扰。

#### PtP 或 PtMP

PtP 和 PtMP 链路在某些方面有所不同。对于 PtMP，您很可能需要一个具有更宽波束的天线，也称为扇区天线。这种天线覆盖更广的角度，但增益也较低，因此距离较短。此外，在 PtMP 中，接入点必须至少具有 RouterOS 软件许可级别 4。连接到接入点的客户端或设备以及 PtP 链路中的设备可以具有许可级别 3 和更窄的波束宽度。

#### 速度

对于短距离链路中的更高速度，您必须选择 60 GHz 设备，对于更长距离——选择 5GHz ac 设备。

#### 注意

对于控制大型接入点网络，您可以使用 CAPsMAN——一个从单一位置配置许多接入点的控制器。使用与您设备菜单匹配的控制器：[WiFi CAPsMAN](./wifi/capsman.md) 适用于 `/interface/wifi` 设备（`wifi-qcom` / `wifi-qcom-ac`），或 [CAPsMAN](./abgn/capsman/index.md) 适用于旧版 `/interface/wireless` 设备。对于控制数百个接入点，我们建议使用我们的 CCR 系列设备。对于控制数千个接入点，您可能需要尝试使用 CHR 或 x86 机器。
