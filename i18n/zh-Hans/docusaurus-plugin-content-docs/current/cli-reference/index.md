# CLI 参考

本 CLI 参考按控制台路径记录了 RouterOS 命令菜单及属性。使用本部分可查阅 RouterOS 功能的命令语法、配置对象及操作命令。

## 参数类型

- **address** — 通用地址参数，显示为 `address (flags=...)`；参见下文 [地址标志](#address-flags)
- **alt** — 替代类型，可接受多种不同值类型中的一种
- **as** — 自治系统号（用于 BGP 路由）
- **bool** — 布尔值（true/false、yes/no）
- **cfg** — 配置条目标识符
- **composite** — 多个参数组合作为一个组处理
- **date** — 日期和时间值
- **enum** — 枚举类型，具有括号中列出的预定义值
- **expr** — 表达式或条件（用于路由过滤和脚本）
- **file** — 文件路径或名称引用
- **iface_enum** — 接口选择列表，通常可接受接口名称，或预定义值如 `all`、`none`、`dynamic`、`slave`；值列于花括号中
- **ipAddr** — IPv4 地址
- **ip6Addr** — IPv6 地址
- **ipPrefix** — 带前缀长度的 IPv4 地址
- **ip6Prefix** — 带前缀长度的 IPv6 地址
- **ipRange** — IPv4 地址范围
- **macAddr** — MAC 地址（可指定完整地址或使用通配符）
- **meter** — 信号质量等级，通常以 dBm 表示
- **multi** — 多值参数，接受定义集合中的多个值
- **num** — 无符号整数，可用范围限制（例如 `[3 .. 20]`、`[.. 10]`、`[4 ..]`）；若未明确指定则为 32 位范围
- **numericon** — 带单位后缀的数值
- **object** — 结构化值列表（例如地址表或配置项表）
- **pic** — 图片/位图值
- **range** — 数值范围（例如一组端口）
- **remote** — 对远程对象的引用（例如路由过滤规则）
- **string** — 文本字符串
- **super** — 复合类型，可接受多种不同参数类型；子类型列于花括号中，例如 `super { bool, time }`
- **switch** — 开关切换，无显式值参数
- **time** — 时间持续时间或间隔，通常以秒为单位，可包含 `s`、`m`、`h`、`d` 等单位
- **timezone** — 时区或 UTC 偏移值
- **ubit** — 具有命名位的位字段，支持的位名称列于括号中，例如 `ubit (ip, ipv6)`
- **value** — 独立值标识符（通常用作复合类型或枚举的一部分）
- **varName** — 变量名称引用（用于脚本）

参数类型可以嵌套，例如 `super {num, time, super {bool, ip}}`。

**address** 类型显示为 `address (flags=...)`，其中标志定义可接受的地址格式：

| 标志 | 含义 |
|------|---------|
| 4    | IPv4 地址 |
| 6    | IPv6 地址 |
| D    | DNS 名称（主机名） |
| i    | 接口名称 |
| /    | 带子网掩码的地址（CIDR 前缀） |
| v    | VRF（虚拟路由转发实例） |
| R    | 路由区分符 |
| S    | 自由格式前缀（例如 EVPN 前缀） |
| \+   | 地址列表 |
| :    | 端口或区域说明符 |
| L    | 链路本地地址 |
| m    | 组播地址 |
