# MikroTik Bluetooth TG-BT5-XX 标签变更日志

> - 新增广告类型“设备名称”。
- 降低设备在活动期间的功耗。对于短间隔广告，功耗将显著降低。
- 如果启用了带温度数据的信标，则降低功耗。
- 降低WDT（看门狗定时器）功耗。如果启用了任何广告间隔小于7秒的信标，此优化将生效。

## 2.5.0

- 新增广告类型“设备名称”。
- 降低设备在活动期间的功耗。对于短间隔广告，功耗将显著降低。
- 如果启用了带温度数据的信标，则降低功耗。
- 降低WDT（看门狗定时器）功耗。如果启用了任何广告间隔小于7秒的信标，此优化将生效。

## 2.4.0

- 在所有广告中包含广告标志字段。
- 新增禁用密码保护的功能。
- 新增禁用加速度计的可能性。
- 为MikroTik格式负载新增选项，以检测禁用的加速度计（标志字段现在可以指示加速度计禁用状态）。
- 允许设置非标准广告间隔。
- 新增配置选项以禁用广告信道。
- 实现了可配置的可连接广告，允许在可配置状态下连接标签，而无需按住磁铁。
- 为加速度计新增配置选项，以设置滤波器类型：HPF、LPF（高通或低通滤波器）。
- 日志功能改进。
