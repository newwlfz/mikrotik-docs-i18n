# MikroTik 有线接口兼容性

## MikroTik SFP/SFP+/SFP28/QSFP+/QSFP28/QSFP56-DD 兼容性

本文展示了 MikroTik 设备与 SFP、SFP+、SFP28、QSFP+、QSFP28 和 QSFP56-DD 收发器的兼容性。文中提供了详细的兼容性表格，为哪些收发器适用于 MikroTik 设备提供了有价值的参考。此外，还提供了一些使用 RouterOS CLI 设置不同数据传输速率的实用配置示例。有关属性的更详细说明，请参阅 [Ethernet](./ethernet.md) 用户手册。

:::info
MikroTik 设备和 SFP、SFP+、SFP28、QSFP+、QSFP28 及 QSFP56-DD 模块对其他厂商的设备没有任何限制。

虽然 MikroTik 无法确保与所有制造商的模块完全兼容，但只要其他厂商的模块和设备符合收发器多源协议 (MSA)，它们就应该与 MikroTik 兼容。

**警告：** RouterOS 默认将 SFP28 和 QSFP28 接口的 **FEC** 模式设置为禁用。为确保与其他厂商设备成功建立链路，您可能需要通过将 FEC 模式配置为 `fec74` 或 `fec91` 来启用它。更多信息请参阅 [Ethernet](./ethernet.md) 用户手册。
:::
